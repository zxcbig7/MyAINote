## 情境：一個只有三個產業的小型經濟體，該怎麼投資五年？

Economic Planning 這一題把整個國家經濟簡化成三個產業：煤（coal）、鋼鐵（steel）、運輸（transport）。每個產業每生產一單位（以一英鎊的產值為單位）的產出，都需要消耗其他產業（也包括自己）的產出作為投入，也需要消耗人力。這是典型的投入產出（input–output）關係，但 Williams 在此加了一個關鍵的時間結構：某年的產出 $t+1$，要靠上一年 $t$ 的投入才能生產出來——也就是說生產有一年的落後（lag）。

事情還沒完。一個產業的產出不會只拿去當年消費掉，也可以拿去**建設產能**：如果今年（年 $t$）某產業投入資源去擴充另一個產業（或自己）的產能，這個新增產能要再過兩年（年 $t+2$）才會正式生效可用。換句話說，這個經濟體同時有兩條時間軸在跑：一條是「短期生產」（落後一年），一條是「長期投資」（落後兩年）。除此之外，貨物存量（stock）也可以跨年儲存，年初（年 0）的存量與各產業現有產能都已知，人力供給每年上限為 £470m。

這正是政府或中央計畫機構在做五年經濟計畫時會面對的問題：要不要現在多蓋一點煤礦產能？還是把資源優先拿去維持當期的鋼鐵、運輸產出？不同的策略偏好會導出完全不同的成長路徑，而這正是本案例真正想教的事。

## 這題示範的建模技巧：動態 Leontief 模型與多期規劃的視界效應

這個模型本質上是一個**動態 Leontief 模型**（dynamic Leontief model）——把經濟學教科書裡靜態的投入產出分析，擴充成跨越多個時期、且投入與產出之間存在時間落差的線性規劃模型。這類「產業互相消耗彼此產出」的經濟模型，正是 [[lp-applications-and-networks]] 談到的產業應用與經濟模型的具體實例，值得對照閱讀該頁了解 LP 在總體經濟建模上的更廣泛用法。

同時，這題也是多期（multi-period）LP 模型的一個好教材，可以與 [[structured-lp-models]] 提到的多期模型技巧對照：模型只規劃五年，但生產與投資的效果會延續到第五年之後。如果建模時天真地假設「世界在第五年結束」，模型就會傾向在最後一年把所有存量、產能都用盡榨乾——反正之後不需要負責——這就是多期規劃裡典型的**視界效應（horizon effect）**，是一個容易踩的建模陷阱。Williams 的處理方式很值得記住：他假設外生需求在第五年之後維持不變、存量维持不變、且第五年後不再新增產能，然後回頭解一個「靜態」Leontief 方程式 $\sum_j c_{ij} x_j = x_i - \text{內生需求}$，求出第六年起三個產業產出的下限（$x_C \ge 116.4$、$x_S \ge 105.7$、$x_T \ge 92.3$）。這個下限被塞進第五年的產能限制式裡，等於是逼模型「留一點餘裕給未來」，而不是在最後一年把資源全部花光。

## 建模過程：變數、限制式與三種目標函數

**決策變數**：
- $x_{it}$：產業 $i$（coal、steel、transport 三者之一）在年 $t$（$t=1,\dots,5$）的總產出。
- $s_{it}$：產業 $i$ 在年 $t$ 初的存量。
- $y_{it}$：產業 $i$ 在年 $t$（$t=2,\dots,6$）新生效的額外產能。

**限制式**分成三組：

第一組是**投入總量平衡**：某年 $t$ 對產業 $i$ 的總投入需求（等於下一年生產所需的投入，加上兩年後產能擴充所需的投入），加上存量的增減，必須等於（外生需求 + 存量變化）：

$$\sum_{j} c_{ij} x_{j,t+1} + \sum_{j} d_{ij} y_{j,t+2} + s_{it} - s_{i,t+1} = \text{該產業的外生需求}$$

其中 $c_{ij}$、$d_{ij}$ 分別是題目 Table 12.1（生產投入係數）與 Table 12.2（產能投入係數）給的數字，$s_{i0}$ 為已知初始存量。

第二組是**人力限制**：每年生產與建產能所需人力總和，不能超過 £470m：

$$0.6x_{C,t+1} + 0.3x_{S,t+1} + 0.2x_{T,t+1} + 0.4y_{C,t+2} + 0.2y_{S,t+2} + 0.1y_{T,t+2} \le 470$$

第三組是**產能限制**：任一年的產出不能超過該產業當時累積的產能（年 0 的初始產能，加上之後陸續生效的所有 $y_{il}$）：

$$x_{it} \le \text{年0初始產能} + \sum_{l \le t} y_{il}$$

模型總共有 45 個變數、42 條限制式。

**目標函數**則刻意設計了三種，用來探討不同的政策優先順序會走出什麼樣的成長路徑：

1. 最大化第五年底的總產能 $\sum_{i} y_{i5}$（同時每年須滿足外生消費需求：煤 £60m、鋼鐵 £60m、運輸 £30m）；
2. 最大化第四、五年的總產出 $\sum x_{it}$（此時忽略外生需求）；
3. 最大化整段期間的總人力需求（同時仍滿足目標 1 的外生需求）。

## 解答與洞見：目標函數的選擇本身就是一個政策決策

三種目標函數解出三種截然不同的五年成長路徑，這正是本案例最有教育意義的地方。

以「最大化第五年產能」為目標時，模型會把資源集中拿去衝煤炭產能——第五年煤炭產能衝到 £1512m，總產能達到 £2142m。原因並不難理解：從 Table 12.2 可以看到，建設一單位煤炭產能所需的其他產業投入相對其他產業更少（尤其煤炭自身投入係數是 0），所以「投資報酬率」最高，模型自然會把資源往這裡傾倒。

以「最大化第四、五年產出」為目標時，資源反而更多地投向運輸業，五年後三個產業產出加總達 £2619m。這是因為運輸業相對其他產業消耗的人力較少，在人力仍是稀缺資源的情況下，把錢投在「省人力」的產業能換到更多總產出。

以「最大化總人力需求」為目標時，煤炭產業又再度被拉高，因為煤炭本身的人力需求係數就偏高，要讓總人力需求最大化，投資自然又流向人力密集的煤炭產業。

這三個結果放在一起看，傳達出一個在 MP 建模實務裡極其重要的教訓：**同一組限制式，換一個目標函數，就會得到方向完全不同的最適解**。模型本身沒有立場，它只會忠實地把你設定的目標推到極致。因此，在真正把這種經濟計畫模型交給決策者使用之前，選擇「該最大化什麼」這件事，其實已經是一個政策辯論，而不是單純的數學問題——這也是為什麼這類總體規劃模型在真正導入一個組織（政府部門、企業規劃單位）決策流程時，往往需要配合大量的溝通與反覆試驗不同情境，而不是算出一個答案就結束。這正呼應了 [[mp-implementation-in-practice]] 談到的、MP 系統要在真實組織中發揮作用，需要的不只是正確的模型，還有讓決策者理解並信任模型輸出的過程。

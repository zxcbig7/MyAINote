## 情境

Food Manufacture 1 是 Williams 這本書 29 個經典案例裡的第一個，題材是食品業裡最常見的問題之一：**blending（調配）**。一家食品廠靠精煉（refine）並混合五種原料油來製造一種食用產品。這五種原料油分成兩大類：VEG 1、VEG 2 屬於植物油（vegetable oils），OIL 1、OIL 2、OIL 3 屬於非植物油（non-vegetable oils）。這個分類不是隨口一提的背景設定，而是直接對應到工廠的實體限制——植物油和非植物油需要不同的精煉產線（production line），任何一個月能精煉的植物油不超過 200 噸、非植物油不超過 250 噸。精煉過程沒有重量損耗，精煉成本也可以忽略不計，題目把焦點完全放在「買什麼、買多少、什麼時候買」這個決策上。

每種原料油都可以「現貨」（January 當月立即交貨）購買，也可以在期貨市場（futures market）預先議定未來某個月交貨的價格。題目給出了 1 月到 6 月、五種油各自的每噸價格表，價格逐月波動——這正是問題的核心張力：如果某個月某種油的期貨價特別便宜，工廠有沒有誘因提前買、囤起來，等到真正要用的月份再拿出來調配？倉儲當然不是免費的，每噸原料油每個月的儲存成本是 £5，最多可以囤到 1000 噸；但最終產品 PROD 不能儲存，精煉過的油也不能儲存——只有「原始、未精煉」的原料油可以進倉庫。

除了產能與價格，還有一項技術限制：最終產品有一個叫做 hardness（硬度）的品質指標，必須落在 3 到 6 之間，而且假設硬度會「線性地」隨配方比例混合（也就是說，混合後的硬度等於各原料油硬度的加權平均，權重就是各原料油在配方中的比例）。工廠一開始（1 月初）每種油都有 500 噸庫存，題目要求 6 月底庫存也必須回到同樣的 500 噸——這個「首尾庫存相等」的設定,让模型自然形成一個封閉的六個月週期。這道題目本身取材自真實案例：人造奶油生產商 Van den Bergs and Jurgens 的大型模型（Williams and Redwood, 1974），書裡只是把它簡化成教學版本。

## 這題示範的建模技巧

Food Manufacture 1 是全書用來示範「**如何把一個單期（single-period）LP 擴充成多期（multi-period）LP**」的第一個範例，對應方法論見 [[structured-lp-models]] 裡討論的多期規劃架構。它同時也示範了 LP 建模裡一個經常被忽略、卻很容易寫錯的地雷：**如何把「品質必須落在某個範圍內」這種比例性質的限制，正確地轉成線性限制式**（而不是天真地把加權和直接拿去跟門檻比較，這樣做在維度上是錯的，下面「建模過程」會詳細解釋）。跟建立線性目標函數與限制式的一般原則,可對照 [[building-lp-models]]。

## 建模過程

### 單期模型（只看 1 月）

如果不考慮儲存,只單獨看 1 月要買多少、怎麼調配,問題可以先簡化成一個很乾淨的單期模型。令 x₁, x₂, x₃, x₄, x₅ 分別代表本月購入的 VEG 1、VEG 2、OIL 1、OIL 2、OIL 3 數量,y 代表本月製造的 PROD 數量。目標是最大化利潤：

```
Maximize PROFIT = -110x₁ -120x₂ -130x₃ -110x₄ -115x₅ +150y
```

利潤 = PROD 的銷售收入(每噸 £150)減去買進五種原料油的成本。限制式有五條：

```
VVEG:  x₁ + x₂                          ≤ 200
NVEG:            x₃ + x₄ + x₅           ≤ 250
UHRD:  8.8x₁ +6.1x₂ +2x₃ +4.2x₄ +5x₅ -6y ≤ 0
LHRD:  8.8x₁ +6.1x₂ +2x₃ +4.2x₄ +5x₅ -3y ≥ 0
CONT:  x₁ + x₂ + x₃ + x₄ + x₅      -y    = 0
```

前兩條(VVEG、NVEG)就是植物油與非植物油各自的精煉產能上限。CONT 是重量平衡式,確保產出 PROD 的重量剛好等於投入的原料油總重(沒有損耗)。真正有意思的是 UHRD、LHRD 這兩條硬度限制式——書裡特別把這裡標成「一個常見的錯誤」拿出來講：很多人第一直覺會把硬度限制寫成

```
8.8x₁ + 6.1x₂ + 2x₃ + 4.2x₄ + 5x₅ ≤ 6
8.8x₁ + 6.1x₂ + 2x₃ + 4.2x₄ + 5x₅ ≥ 3
```

這樣寫在**維度上是錯的**：左邊是「硬度 × 數量」的量綱,右邊 3、6 卻是純粹的硬度值,兩邊根本不能比較。硬度是一個**比例性質**(intensive property),必須用「每個原料油佔配方的比例」x_i/y 來表示,而不是絕對數量 x_i。正確的寫法應該是 Σ(hardness_i · x_i/y) ≤ 6 與 ≥ 3,再把不等式兩邊同乘 y(y 恆為正,乘法方向不變),就得到上面線性化後的 UHRD 與 LHRD。這是一個值得牢記的建模教訓：**任何「平均值/比例落在某範圍」的限制,都不能直接對總量做加權和比較,必須先除以基準量、化簡成比例形式,才能轉回線性限制式**。

### 多期模型(完整六個月)

要讓模型能考慮「現在囤貨、以後用」這種跨期決策,必須把每種原料油在每個月的「買、用、存」都拆成獨立的變數。書裡用 BVEG11、UVEG11、SVEG11(數字 11 代表「油1、月份1」)這種命名法,對五種油、六個月各自定義 buy / use / store 三組變數。這些變數之間必須用一條「存量平衡式」串起來：

```
上月存量 + 本月買入量 = 本月使用量 + 本月存量
```

以 VEG 1 為例,月0(期初)與月6(期末,即 6 月底)的存量都固定在 500 噸,於是六條連鎖限制式長這樣:

```
BVEG11 - UVEG11 - SVEG11         = -500
        SVEG11 + BVEG12 - UVEG12 - SVEG12 = 0
                 SVEG12 + BVEG13 - UVEG13 - SVEG13 = 0
                          SVEG13 + BVEG14 - UVEG14 - SVEG14 = 0
                                   SVEG14 + BVEG15 - UVEG15 - SVEG15 = 0
                                            SVEG15 + BVEG16 - UVEG16 = 500
```

其餘四種油也各自需要六條同樣結構的限制式。書裡建議乾脆多定義兩個「虛擬」變數 SVEG10 與 SVEG16 並把它們直接 fix 在 500,這樣六條式子的形式可以完全統一,不用特別處理頭尾邊界。目標函數裡,買進變數依各月期貨價格給係數,儲存變數給 £5(或寫成利潤 -£5),六個 PROD 變數各自給 £150 利潤。整個模型最終長到 91 個變數(30 個買進 + 30 個使用 + 25 個儲存 + 6 個產品)、60 條限制式(30 條調配限制,結構同單期模型;30 條存量連鎖限制)。

書裡還特別點出這種模型在實務上該怎麼用:公司不會只解一次就一路照做六個月,而是每個月都重新求解一次——1 月先用這個模型定出 1 月的確定計畫,連帶得到 2-6 月的「暫定」計畫；到了 2 月,再用當時最新的資訊重新求解,把 2 月確定下來、順帶更新 3-7 月的暫定計畫,依此類推。這就是後來在時間序列規劃裡常說的 rolling horizon(滾動視界)做法的雛型,讓每個月的決策都建立在當下最新資訊上,而不是死守六個月前訂出的舊計畫。

## 解答與洞見

Part IV 給出的最佳解(Table 14.1)顯示出一個典型的「套利式」調配策略:某些月份完全不買(1 月、3 月、4 月都是 Nothing),靠期初庫存調配;2 月買入 250 噸 OIL 2、5 月買入 500 噸 OIL 3、6 月一口氣買進大量三種油——這正呼應了「期貨價格逐月波動、模型會自動找出最划算的購買時機」的設計初衷。最終利潤是 **£107,843**(銷售收入減原料成本,含最後一個月的儲存成本),書裡也提醒這題存在多組交替最佳解(alternative optima)——LP 在某些方向上退化時常見的現象,代表除了 Table 14.1 這組解以外,還有其他買/用/存的組合可以達到一模一樣的利潤,對照 [[interpreting-lp-solutions]] 裡對解的唯一性與驗證方法的討論。

這個案例最重要的洞見不是最終數字,而是它示範了兩件事:第一,一個看起來單純的「買什麼、調配什麼」問題,一旦加上時間維度與儲存決策,規模會迅速膨脹(從 6 條式子、6 個變數,變成 60 條式子、91 個變數),這正是 [[structured-lp-models]] 強調的多期模型典型特徵;第二,硬度限制式的維度陷阱提醒我們,建模時要對每一條限制式的「量綱」保持警覺,而不是看到「加權和 ≤ 上限」就直接照抄。

## 情境

問題本身樸素到幾乎像一堂統計課的開場白：已知某個量 $y$ 依賴另一個量 $x$，蒐集到 19 組對應的觀測值 $(x_i, y_i)$（$x$ 從 0 到 10），要找出一條「最佳」曲線去描述這組資料。書裡一次問了三件事：(1) 用直線 $y = bx + a$ 擬合，目標是讓所有點與直線之間的*絕對離差總和*最小；(2) 一樣擬合直線，但目標換成讓*最大離差*最小；(3) 改用二次曲線 $y = cx^2 + bx + a$ 擬合，同樣的兩種目標都要做一次。

任何學過統計的人看到「幫資料找一條最佳擬合曲線」都會直覺想到迴歸分析（regression），而迴歸分析的教科書標準做法是最小平方法（least squares）：讓離差平方和最小。但這裡書刻意不用平方和，而是用絕對值總和與最大絕對值兩種目標。這個選擇不是隨意的——它把一個原本要用微積分求解的迴歸問題，變成一個可以直接丟給 LP solver 的線性規劃問題。這正是這個案例值得放進建模資料庫的原因：它示範了「選對衡量誤差的方式，可以把一個看似非線性的統計問題變成純粹的 LP」。

## 這題示範的建模技巧

核心技巧有兩層。第一層是延續 §3.3 討論過的 goal programming 手法：每一筆觀測資料 $(x_i, y_i)$ 都對應一條限制式，用一對非負的偏差變數 $u_i, v_i \ge 0$ 分別代表「預測值高於觀測值」與「預測值低於觀測值」的量，於是離差的絕對值就被拆成兩個方向的距離，而不必在目標式裡直接寫 $|{\cdot}|$。第二層技巧是把「minimize 最大離差」這種 minimax（非線性、不可微分）的目標，透過引入一個新變數 $z$ 和一組不等式 $z \ge u_i$、$z \ge v_i$ 轉成單純的線性目標 minimize $z$——這是所有把「minimize the max of several量」轉成 LP 的標準寫法（epigraph trick），在 IP/LP 建模裡到處都會遇到。

更值得注意的是第三個延伸：把直線換成二次曲線 $y = cx^2 + bx + a$ 之後，資料點 $x_i^2$ 是已知常數，$c$ 仍然是要求解的自由變數，整條限制式 $cx_i^2 + bx_i + a + u_i - v_i = y_i$ 對 $(a,b,c,u_i,v_i)$ 而言依然是線性的。換句話說，「曲線本身對 $x$ 而非線性」不等於「模型對決策變數非線性」——這正是 [[nonlinear-and-separable-programming]] 反覆強調的判斷準則：先問清楚「非線性」出現在哪一組變數上，再決定要不要真的動用非線性規劃或 separable programming 的機器。這裡因為非線性只發生在已知的 $x$ 上，而不是待解的係數上，所以整個二次曲線擬合問題仍然是一個貨真價實的 LP。

## 建模過程

以 case (1)（直線、絕對離差總和）為例，模型長相如下：

- 決策變數：$a, b$ 為自由變數（可正可負，因為擬合直線的截距與斜率沒有正負限制）；每筆資料 $i = 1, \dots, 19$ 各有一對 $u_i, v_i \ge 0$。
- 限制式：$bx_i + a + u_i - v_i = y_i$，$i = 1, \dots, 19$。
- 目標：minimize $\sum_i u_i + \sum_i v_i$。

這個模型共有 19 條限制式、40 個變數（19 筆資料各 2 個偏差變數，加上 $a, b$）。

case (2)（直線、最大離差）在此基礎上加入變數 $z$ 與 38 條額外限制式 $z - u_i \ge 0$、$z - v_i \ge 0$（$i=1,\dots,19$），目標改成單純 minimize $z$——$z$ 的最小值會自動等於所有 $u_i, v_i$ 中的最大值，因為求解過程會把 $z$ 壓到剛好卡住最緊的那個離差。

case (3)（二次曲線）只需要在第一組限制式裡加入一個新的自由變數 $c$，把 $bx_i + a + u_i - v_i = y_i$ 換成 $cx_i^2 + bx_i + a + u_i - v_i = y_i$，兩種目標（總和／最大值）都可以直接沿用前面的寫法，不需要改動任何求解邏輯——這也再次印證了「只要限制式對決策變數保持線性，換多複雜的基底函數（多項式次數再高都行）都不影響這仍是一個 LP」。

## 解答與洞見

四組結果攤開來看非常有教學意義：

- 直線、絕對離差總和：$y = 0.6375x + 0.5812$，總離差約 11.46。
- 直線、最大離差：$y = 0.625x - 0.4$，最大離差 1.725（三個點 $(3.0, 3.2)$、$(5.0, 1.0)$、$(7.0, 5.7)$ 同時卡在這個上限），但總離差反而變差，來到 19.95（相對於前一條直線的 11.47）。
- 二次曲線、絕對離差總和：$y = 0.0337x^2 + 0.2945x + 0.9823$，總離差降到 10.45（比直線好，畢竟多了一個自由度）。
- 二次曲線、最大離差：$y = 0.125x^2 - 0.625x + 2.475$，最大離差壓到 1.475（四個點 $(0.0,1.1)$、$(3.0,3.2)$、$(5.0,1.0)$、$(7.0,5.7)$ 同時頂到這個上限）。

兩組直線解放在一起比較，會看到一個很經典的取捨：以總離差為目標的解，把誤差分散給多個點去承擔，整體表現最好，但沒有對任何單一點的誤差設下限制；以最大離差為目標的解，明確保證「沒有一個點錯得太離譜」，代價是整體累積誤差變差。而兩種目標剛好都被同一個資料點 $(5.0, 1.0)$ 卡住——這個點明顯低於整體趨勢（其他 $x$ 附近的 $y$ 都在 3 以上），是視覺上一眼可見的離群值。最大離差目標對這種單一離群點特別敏感（它直接決定了整個目標值），而總離差目標則相對穩健，不會因為一兩個離群點而大幅改變擬合結果。

這正好可以拿來跟統計學裡的最小平方法（least squares）三方對照：最小平方法用離差平方和當目標，有解析解（常態方程式）、計算方便、在高斯-馬可夫假設下有良好的統計性質，但因為誤差被平方，對離群值反而*更*敏感（一個離群點的貢獻會被放大）；總離差最小（L1 迴歸）對離群值最穩健，但沒有解析解——不過正因為它是線性的，直接丟給 LP solver 求解毫無困難；最大離差最小（Chebyshev/minimax）則是三者中對單一最壞點最敏感、但也是唯一能明確保證「任何一點的誤差都不超過某個界線」的方法，適合需要對最壞情況設保證的場景。三種目標對應三種不同的誤差哲學，而 LP 恰好把後兩種都變得跟解一個標準 LP 一樣容易，這是純統計方法做不到的。書中也提到 Williams and Munford (1999) 對這類問題有進一步的解析解討論，顯示 LP 解法與統計理論之間其實有更深的連結可以挖。

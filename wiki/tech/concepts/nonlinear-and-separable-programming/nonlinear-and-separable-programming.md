# 第七章:當模型不再是線性的

[[building-lp-models]] 討論線性規劃時,曾經指出線性成立需要三個前提:資源的使用有固定的規模報酬(constant returns to scale)、一項活動使用資源的量與活動水準成正比、多項活動使用同一資源的總量等於各活動個別用量的加總。現實世界並不總是這麼配合。單價會隨著產量改變、單位成本會隨著規模產生遞增或遞減的效應、需求會隨著售價變動——這些現象一旦出現在模型裡,目標函數或限制式就不再是線性的,我們稱之為 **non-linear model**(非線性模型)。

非線性模型比同樣規模的線性模型難解得多,這是本章要處理的核心矛盾:一方面,非線性現象在實務中無所不在;另一方面,通用的非線性求解演算法遠不如 LP 的 simplex algorithm 成熟、可靠。本章要回答的問題是:什麼時候非線性模型「還算好處理」、什麼時候它會變得棘手,以及有沒有辦法把非線性問題「偽裝」成 LP 的樣子,借用 LP 成熟的求解能力來對付它。答案的關鍵字是 **separable programming**(可分規劃)——一種透過分段線性近似(piecewise linear approximation),把非線性問題轉換回接近 LP 形式的技巧。

## 7.1 非線性從哪裡冒出來:典型應用

最常見的非線性來源,是**單位利潤或單位成本隨產量改變**。延續 [[interpreting-lp-solutions]] 用過的 product mix 例子:如果每單位 PROD 1 固定貢獻 £550 利潤,目標函數裡就是線性項 $550x_1$。但如果單位利潤其實會隨著產量 $x_1$ 增加而提高,例如變成 $550+2x_1$,目標函數就會出現非線性項 $2x_1^2$。這種「量越大、單位利潤越好」的情形稱為 **increasing returns to scale**(規模報酬遞增);相反地,如果單位利潤隨產量增加而下降(例如變成 $550/(1+x_1)$),則稱為 **decreasing returns to scale**(規模報酬遞減)。這兩種效應與線性(constant returns to scale)放在一起比較,可以用總利潤對產量作圖來直觀理解:

| 規模報酬型態 | 總利潤/總成本曲線形狀 | 典型非線性項 |
| --- | --- | --- |
| constant(線性) | 一直線 | 無(仍是 $550x_1$) |
| increasing(遞增) | 越來越陡峭上翹 | $2x_1^2$ |
| decreasing(遞減) | 越來越平緩趨於飽和 | $550x_1/(1+x_1)$ |

另一個很常見的非線性來源,是**售價本身受產量影響**——也就是需求曲線的存在。如果生產 $x$ 單位、單位成本是 $c$、而單位售價 $p(x)$ 本身是 $x$ 的函數,則利潤貢獻是

$$p(x)\,x-cx$$

這裡的 $p(x)\,x$ 就是一個非線性項。最簡單的處理方式,是假設 $p(x)$ 本身是 $x$ 的線性函數,這樣一來目標函數裡會出現二次項,整個模型變成所謂的 **quadratic programming**(二次規劃)模型——書中提到的 AGRICULTURAL PRICING 案例正是這一類應用的例子。更精細一點的做法,是透過 **price elasticity of demand**(需求的價格彈性)$E_x$ 來描述 $p(x)$ 與 $x$ 的關係:

$$E_x=\frac{\text{需求量的百分比變化}}{\text{價格 }p(x)\text{ 的百分比變化}}$$

如果把 $E_x$ 視為在所關心的範圍內大致固定,可以推導出 $p(x)=k/x^{1/E_x}$(其中 $k$ 是需求降到 1 單位時對應的價格上限),對應到目標函數裡的非線性項就是 $p(x)\,x=kx^{1-(1/E_x)}$。

除了目標函數,非線性也可能出現在**限制式**裡。摻配(blending)問題是一個常見場景:如果某項品質規格(例如硬度)並非各原料比例的線性組合,限制式本身就會帶有非線性項。另外還有一類叫做 **geometric programming** 的模型,限制式裡的非線性項全部是多項式形式(例如 $x_1x_2x_3+2x_2^2x_3\le 32$),這類模型在工程領域相對常見,但在管理類應用中則相對少見。

## 7.2 局部最佳解與全域最佳解:convex 與 non-convex 的關鍵分野

一旦目標函數或限制式出現非線性,馬上會冒出一個線性規劃裡完全不存在的麻煩:**求解演算法找到的「最佳解」,有可能只是一個局部的最佳解,而不是真正整體意義下的最佳解**。要理解這個現象,必須先建立 **convex**(凸)與 **non-convex**(非凸)這組概念,這是本章,乃至於整個非線性規劃領域,最重要的一組分類。

**Convex 區域的定義**:一個空間中的區域,如果區域內任兩點之間的直線段完全落在這個區域內部,就稱為 convex region(凸區域)。反之,只要能找到區域內兩點,使得連接兩點的直線段有一部分跑出區域之外,這個區域就是 non-convex(非凸)的。

**Convex 函數的定義**:一個函數 $f(x)$,如果它「上方」的點集合 $\{(x,y): y\ge f(x)\}$ 構成一個 convex region,就稱 $f(x)$ 是 convex function(凸函數)。舉例來說,$x^2$ 是 convex function,因為它上方那塊區域(拋物線開口向上的內部)是一個凸區域;而 $2-x^2$(開口向下的拋物線)則是 non-convex,因為它上方的區域是一塊「凹進去」的形狀,任兩點的連線容易跑出區域之外。

有了這兩個定義,就可以定義 **convex programming model**:一個極小化 convex function、且可行域本身是 convex region 的數學規劃模型,稱為 convex programming model。(注意:因為極小化一個 convex function 等價於極大化這個函數的負值,而負的 convex function 恰好符合對應的極大化情境,所以這個定義同時涵蓋了適當定義下的極大化問題。)

這個定義帶出一個重要結論:**linear programming 是 convex programming 的一個特例**。任何 LP 模型都能表示成極小化的形式,而線性函數天生滿足 convex function 的定義;同時,由一組線性限制式圍出來的可行域,也能證明必然是 convex region。這解釋了為什麼 LP 從來不必擔心局部最佳解的問題——它其實一直活在 convex programming 這個「安全」的子類別裡,只是我們平常不會特別強調這一點。

### Convex 與 non-convex 模型的實際差異

書中用兩個結構幾乎一模一樣、只差目標函數的例子,直接對比出 convex 與 non-convex 模型的行為差異。兩者共用同一組限制式

$$x_1+x_2\le 4,\qquad 2x_1+x_2\le 5,\qquad -x_1+4x_2\ge 2,\qquad x_1,x_2\ge 0$$

**Example 7.1(convex 模型)**:目標函數是 $x_1^2-4x_1-2x_2$,這是一個 convex function。把不同目標值所對應的等高線畫在可行域上,會發現這些等高線一律朝著遠離可行域的方向彎曲。這帶來一個非常實用的性質:只要沿著等高線持續改善(往更好的目標值移動),就絕對不會有機會再彎回到可行域裡面——換句話說,任何演算法只要找到一個在局部意義下無法再改善的點,那個點必然就是全域最佳解。

**Example 7.2(non-convex 模型)**:目標函數改成 $-4x_1^3+3x_1-6x_2$,這是一個 non-convex function(即使限制式與可行域完全沒變,依然是 convex region)。這一次,不同目標值的等高線會朝可行域的方向彎曲,甚至可能繞回可行域內部。這造成一個危險的後果:某個點 A 在目標值等高線經過它時,看起來兩個方向都正在遠離可行域,一般演算法會誤判這已經是最佳解;但事實上,等高線稍微移動一下,可能會重新繞回可行域,在另一個角落(點 B,甚至更遠的點 C)找到更好的目標值。點 A、點 B 這種「所在位置的四周都無法再改善,但整個可行域裡其實還有更好的點」,就稱為 **local optimum**(局部最佳解);真正整個可行域裡最好的那個點(本例中的點 C),才是 **global optimum**(全域最佳解)。

書裡有一個很生動的比喻,值得記住:一群登山者在濃霧中攀登一片山脈,他們很容易判斷自己何時站上了一個山頭——因為不論往哪個方向走,地面都在往下降。但這並不保證附近沒有藏在濃霧裡、更高的另一座山峰。許多非線性規劃的計算方法(包括本章稍後要介紹的 separable programming),本質上就和這群濃霧中的登山者一樣,只能保證找到一個「局部」的山頭,不能保證那是整片山脈裡最高的一座。

### 與規模報酬的呼應

這組 convex / non-convex 的分類,恰好可以拿來重新解釋 7.1 節提到的規模報酬現象。當我們面對的是 **diseconomies of scale**(規模不經濟,也就是單位成本隨產量遞增)時,總成本函數會越漲越陡,這樣的成本函數是 convex 的;反過來,**economies of scale**(規模經濟,單位成本隨產量遞減)則會讓總成本曲線越來越平緩趨於飽和,對應到一個 non-convex 的成本函數。這意味著,只要一個問題的非線性完全來自於「規模不經濟」,不論它有多少變數,理論上都保證任何找到的局部最佳解就是全域最佳解;但只要牽涉到規模經濟(以及其他任何造成 non-convex 目標函數或可行域的原因),就必須提防局部最佳解的陷阱,需要更謹慎、也通常更昂貴的求解手段。

要在一個大型的實務模型裡,單靠人工判斷它究竟屬於 convex 還是 non-convex,往往不是一件容易的事;對於已知是 convex 的問題(例如純粹的規模不經濟,且限制式都是可分函數),下一節介紹的 separable programming 已經足夠;但對於 non-convex,或者根本無法確定凸性的問題,separable programming 只能保證找到局部最佳解,想要真正保證找到全域最佳解,通常得訴諸計算成本高得多的 integer programming 手段(見 [[integer-programming-fundamentals]] 與書中 Section 9.2、9.3 對此的延伸討論)。

## 7.3 Separable programming:把非線性偽裝成分段線性

理解了 convex/non-convex 的差異之後,自然會問:有沒有辦法讓一般的 LP 求解工具,也能拿來處理非線性問題?答案的鑰匙是 **separable function** 這個概念。

**定義**:一個函數如果可以寫成若干個「單變數函數」的加總,就稱為 separable function(可分函數)。例如

$$x_1^2+2x_2+e^{x_3}$$

是 separable 的,因為 $x_1^2$、$2x_2$、$e^{x_3}$ 分別只涉及一個變數。但

$$x_1x_2+\frac{x_2}{1+x_1}+x_3$$

不是 separable 的,因為 $x_1x_2$ 與 $x_2/(1+x_1)$ 都同時涉及兩個變數。

Separable function 之所以重要,是因為它們可以被逐一針對每個單變數函數,用**分段線性函數**(piecewise linear function)去近似。一旦整個模型都被改寫成分段線性的形式,就可以借用(擴充過的)simplex algorithm 來求解,convex 問題能得到全域最佳解,non-convex 問題至少能得到一個局部最佳解。這正是 separable programming 的核心思路:先確認(或設法把)問題寫成 separable 的形式,再用分段線性近似把它「拉回」LP 能處理的世界。

### 用 λ-form 建立分段線性近似

以 Example 7.1 裡出現的非線性項 $x_1^2$ 為例,示範具體做法。從限制式可以推知 $x_1$ 不可能超過 2.5,因此只需要在 $[0,2.5]$ 這個範圍內近似 $y=x_1^2$。把這段曲線切成三段折線(對應四個端點,標記為 0、A、B、C,例如 $x_1=0,1,2,2.5$),接著引入一組新的權重變數 $\lambda_1,\lambda_2,\lambda_3,\lambda_4$,分別代表這四個端點的權重,並加入以下限制式:

$$x_1=0\lambda_1+1\lambda_2+2\lambda_3+2.5\lambda_4$$
$$y=0\lambda_1+1\lambda_2+4\lambda_3+6.25\lambda_4$$
$$\lambda_1+\lambda_2+\lambda_3+\lambda_4=1$$

再加上一條額外的邏輯規定:

$$\text{最多只允許兩個「相鄰」的 }\lambda_i\text{ 同時非零}$$

有了這幾條式子,原本模型裡的非線性項 $x_1^2$ 就可以整個被單一的線性變數 $y$ 取代。前三條式子保證 $(x_1,y)$ 這一對數值,必然落在 0、A、B、C 這四個端點所連成的折線上的某一段;而「最多兩個相鄰 $\lambda_i$ 非零」這條規定,則是為了避免出現例如 $\lambda_1=1/3,\lambda_3=2/3$(其餘為零)這種不相鄰的組合——雖然它同樣滿足前三條線性限制式,卻會讓 $(x_1,y)$ 落到折線之外、不對應任何真實的 $(x_1,x_1^2)$ 組合,是一個「假的」解。

這個「最多兩個相鄰 $\lambda_i$ 非零」的規定,本質上是一種邏輯條件,一般沒辦法直接寫成線性限制式,通常需要靠整數規劃的 0-1 變數才能精確表達(詳見書中 Section 9.3,以及 [[integer-programming-fundamentals]] 對 0-1 變數表達邏輯條件的討論)。但這裡有一個非常關鍵、值得特別記住的簡化:**如果原始問題本身是 convex 的**,這條邏輯規定會在最佳解中「自動」被滿足,完全不需要額外用整數變數去強制它。原因並不難理解:對一個 convex(此處為極小化)問題來說,任何試圖跳過折線、直接取「折線上方」兩個不相鄰端點加權平均的解,得到的 $(x_1,y)$ 座標必然落在真正曲線的**上方**;而演算法在追求極小化 $y$ 的過程中,自然會被吸引去尋找更低、也就是真正落在折線上的點。換句話說,convex 問題的幾何形狀本身,已經替我們把「不合法」的解淘汰掉了。

反之,對於 Example 7.2 那樣的 non-convex 問題(這裡改成近似非線性項 $x_1^3$),情況正好相反:演算法為了讓目標函數盡可能小(而 $-4x_1^3$ 這一項驅使演算法傾向讓 $y=x_1^3$ 盡量*大*),反而有誘因去選擇「跳出折線、往上方偏移」的不合法組合。這時「最多兩個相鄰 $\lambda_i$ 非零」這條規定就不會自動滿足,必須靠專門設計的演算法去強制執行。**Separable programming algorithm**(Miller, 1963,是對 simplex algorithm 的一種擴充)正是為了處理這種情況而生:它在執行過程中會主動限制,任何時候最多只允許兩個相鄰的 $\lambda_i$ 進入基底解(basis),藉此保證取得的解永遠對應折線上真實存在的點。但要注意,即使有了這個保證,對 non-convex 問題而言,演算法找到的依然只是一個 **local optimum**——它可能停在點 A 或點 B,而不是真正最好的點 C(呼應 7.2 節的討論)。實務上常見的因應之道,是用不同的起始策略多跑幾次,再從得到的幾個局部最佳解裡挑出最好的一個,以此提高逼近全域最佳解的機會,但這終究不是一個有理論保證的做法。

### δ-form:另一種等價的建構方式

除了上面介紹的 **λ-form**(把 $\lambda_i$ 詮釋為附加在折線頂點上的權重),還存在一種替代寫法叫做 **δ-form**。這一次引入的變數 $\delta_1,\delta_2,\delta_3,\dots$ 分別代表 $x_1$ 落在每一段區間內、佔滿該區間長度的**比例**,例如

$$x_1=\delta_1+\delta_2+0.5\delta_3,\qquad y=\delta_1+3\delta_2+2.25\delta_3,\qquad 0\le\delta_1,\delta_2,\delta_3\le 1$$

搭配的邏輯規定變成:「只要某個 $\delta_i$ 非零,它前面的所有 $\delta_i$ 必須等於 1,它後面的所有 $\delta_i$ 必須等於 0」——這條規定同樣是為了確保 $\delta$ 變數是依序、逐段被填滿,而不是跳著填。書中特別指出一個實務上的差異:**λ-form 拿掉邏輯規定之後的線性鬆弛(relaxation),會比 δ-form 拿掉邏輯規定之後的線性鬆弛更「緊」**——也就是說,如果之後要進一步靠整數變數收緊這條邏輯規定(如 Section 9.3 所述),從 λ-form 出發通常會有更好的計算表現。

## 7.4 把一個問題轉換成 separable 形式

前面的討論建立在一個前提上:模型裡的非線性項本身就是單變數的、separable 的。但現實中大量的非線性項,例如兩個變數的乘積 $x_1x_2$,天生就不是 separable 的。這一節要說明的是:即使遇到這種「非 separable」的非線性項,往往還是有辦法透過引入額外變數,把整個模型改寫成完全 separable 的形式,再套用前一節的分段線性近似技巧。這也是為什麼 separable programming 適用的範圍,遠比字面上「只能處理單變數非線性」聽起來的還要廣。

**做法一:代數變數變換。** 針對乘積項 $x_1x_2$,引入兩個新變數

$$u_1=\tfrac12(x_1+x_2),\qquad u_2=\tfrac12(x_1-x_2)$$

可以用簡單代數驗證 $u_1^2-u_2^2$ 恆等於 $x_1x_2$。只要把 $u_1,u_2$ 的定義式當作等式限制式加進模型,原本的 $x_1x_2$ 就能被 $u_1^2-u_2^2$ 取代——而 $u_1^2$ 與 $u_2^2$ 都是單變數的非線性函數,自然是 separable 的,可以各自用分段線性近似處理。這裡有一個容易被忽略的細節:$u_2$ 的可能取值範圍往往包含負值,如果目標是用書中定義的方式建立分段線性近似,可能需要對 $u_2$ 做適當的平移,或者乾脆把它宣告為 **free variable**(自由變數,也就是不限制非負的 LP 變數)來處理。如果模型裡出現的是三個以上變數的乘積(例如某些 geometric programming 模型),同樣的代數變換手法可以反覆套用,一步步把多變數乘積拆解回單變數的 separable 形式。

**做法二:取對數。** 另一種處理 $x_1x_2$ 這類乘積項的方式,是引入一個新變數 $y$ 代表這個乘積本身,並用一條非線性等式限制式把三者連結起來:

$$\log y=\log x_1+\log x_2$$

這條限制式本身雖然是非線性的,但它涉及的 $\log y,\log x_1,\log x_2$ 都是各自變數的單變數函數,因此仍然是 separable 的。使用這個方法時必須格外小心:一旦 $x_1$ 或 $x_2$(從而 $y$)可能取值為 0,對應的對數就會趨向 $-\infty$,造成數值上的問題,通常需要事先把 $x_1,x_2$ 平移一個常數,確保它們恆為正值。另外,Beale(1975)也提醒過,如果模型中同時出現一個變數本身與它的對數(例如同時有 $x_1$ 與 $\log x_1$ 這兩項),而兩者數量級差異懸殊,很容易造成數值上的不穩定,求解時要特別留意。

無論採取哪一種轉換方式,都要付出代價:引入新變數與新的等式限制式,會讓模型的規模膨脹,連帶拉長求解所需的時間。但這個代價通常是值得的——它把一個原本無法直接套用 LP 技術的非線性問題,轉換成了一個(可能規模更大,但)可以借助成熟、可靠的 LP 求解流程來處理的問題。這種「先想辦法轉換成 separable 形式,再做分段線性近似」的兩段式思路,正是本章從 7.1 節的各種非線性現象,一路收斂到一套具體可操作方法的完整脈絡。

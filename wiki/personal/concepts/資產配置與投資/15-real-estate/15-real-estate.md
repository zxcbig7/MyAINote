# 第 15 章（補充篇）：房地產 — 你人生最大的一筆配置決定

> ⚠️ 稅制、貸款成數、利率、政策工具都會變動，**執行前查財政部、央行與各銀行的當年度規定**。本章講的是**判斷框架**，不是可以照抄的數字。

## 為什麼補這一章

第 4 章說過本書「不談房地產的細節」，因為它太大、太複雜，值得單獨一本書。

但這個切割在實務上撐不住。理由很簡單：**對台灣的工程師來說，買房是你這輩子單筆金額最大的財務決定，而它會同時改變你資產配置的每一個部分**——現金部位、股票比例、風險承受能力、緊急預備金需求、甚至你的職涯流動性。

不談它，前面十四章就有一個很大的洞。

所以這一章不教你「怎麼挑房子」「怎麼看地段」，那些網路上很多。它只回答三個財務問題：

1. **租還是買，怎麼「正確地」比較？**
2. **買了之後，我的資產配置要怎麼變？**
3. **房貸這個槓桿，我該怎麼看待？**

## 一、房子有兩個身分，混在一起就會算錯

一間自住的房子同時是：

| 身分 | 意思 |
| --- | --- |
| **消費品** | 你住在裡面，它提供居住服務。這部分跟租房是同一件事——你在買「住的權利」 |
| **投資品** | 它是一項資產，價格會漲會跌 |

**新手最常犯的錯是只看第二個身分**：「租房是幫房東繳貸款，買房是幫自己存錢」。

這句話的問題在於，它把**房貸支出全部當成儲蓄**，但實際上：

```text
每月房貸月付金
  ├── 本金部分  ← 這才是「存下來」的
  └── 利息部分  ← 這是純支出，跟房租一樣有去無回
```

而在本息均攤的**前幾年，利息佔月付金的比例極高**。一筆 30 年期的房貸，前五年繳的錢裡有相當大一部分是利息。

**所以正確的比較不是「房貸 vs 房租」，是「持有成本 vs 房租」。**

## 二、租 vs 買的正確算法

### 持有成本（ownership cost）

真正該拿去跟房租比的是這個：

```text
年持有成本
  = 房貸利息
  + 房屋稅 + 地價稅
  + 管理費
  + 保險（火險/地震險）
  + 修繕與折舊準備（老屋更高）
  + 頭期款的機會成本 ← 最常被漏掉的一項
  − 房價增值（未實現，且不確定）
```

**「頭期款的機會成本」是關鍵的一項。** 如果你拿 400 萬當頭期款，那 400 萬原本可以投入市場產生報酬。這筆放棄掉的報酬是真實的成本，只是它沒有出現在任何帳單上。

### 一個具體的對照架構

假設一間 1,600 萬的房子，頭期款 400 萬、貸款 1,200 萬：

| 項目 | 年金額（示意） |
| --- | --- |
| 房貸利息（初期，利率 2%） | 約 24 萬 |
| 房屋稅 + 地價稅 | 依地區與稅基 |
| 管理費 | 約 3~6 萬 |
| 修繕折舊準備（房價的 0.5%~1%） | 約 8~16 萬 |
| **頭期款機會成本**（400 萬 × 5%） | **約 20 萬** |
| 交易成本攤提（仲介、代書、契稅、裝潢） | 通常 3%~6% 的房價，攤到持有年數 |
| **合計（未計增值）** | **每年數十萬** |

拿這個數字去跟「租同樣一間房要多少錢」比，才是有意義的比較。

### 一個更快的指標：房價租金比

```text
房價租金比 = 房價 ÷ 年租金
（或反過來看：租金收益率 = 年租金 ÷ 房價）
```

粗略的判讀：

| 房價租金比 | 租金收益率 | 大致判讀 |
| --- | --- | --- |
| < 20 | > 5% | 買通常划算 |
| 20 ~ 30 | 3.3% ~ 5% | 灰色地帶，看個人 |
| **> 30** | **< 3.3%** | **租通常在財務上較划算** |

> 📌 **台灣（尤其雙北）的租金收益率長期偏低**，常見的量級在 **1.5% ~ 2.5%**，也就是房價租金比 40 以上。

**這代表什麼？** 純從「居住成本」的角度看，在台灣租房通常比買房便宜——買房划算與否，**高度依賴房價繼續上漲**。

這不是說不該買。這是說：**你要誠實承認，你買房的財務報酬有很大一部分押在「未來房價會漲」這個假設上。** 用第 2 章的框架講，你買的東西的現金流（租金）報酬率很低，剩下的都要靠估值變化。

### 但財務不是全部

上面全是算術。實際決定還有這些**非財務因素**，而且它們是正當的：

| 買房的非財務價值 | 說明 |
| --- | --- |
| **居住穩定性** | 不會被房東收回、不用搬家、小孩學區穩定 |
| **可自由裝修** | 這對長期居住品質的影響很大 |
| **心理安全感** | 這是真實的價值，不要因為「不理性」就否定 |
| **強制儲蓄** | 房貸逼你每月存下本金部分 |
| 對抗租金上漲 | 房貸鎖住居住成本（但機動利率會變，見後） |

| 買房的非財務代價 | 說明 |
| --- | --- |
| **地理流動性歸零** | 這對工程師特別重要，下面單獨講 |
| 換屋摩擦極大 | 交易成本高、時間長 |
| 修繕與管理的心力 | 這是實際的時間成本 |

**結論**：如果你是因為「想要一個穩定的家」而買房，那是好理由。如果你是因為「買房比較划算」而買房，**先把上面的算術做一次**。

## 三、房貸是槓桿 —— 這件事要講清楚

### 你買的曝險是頭期款的四到五倍

拿 400 萬買 1,600 萬的房子，**你的房地產曝險是 1,600 萬，不是 400 萬**。這是 4 倍槓桿。

用具體數字看槓桿如何放大：

| 房價變化 | 房子價值 | 你的淨值（房價 − 貸款 1,200 萬） | 相對頭期款的變化 |
| --- | --- | --- | --- |
| +20% | 1,920 萬 | 720 萬 | **+80%** |
| 0% | 1,600 萬 | 400 萬 | 0% |
| −20% | 1,280 萬 | 80 萬 | **−80%** |
| −25% | 1,200 萬 | **0** | **−100%** |

**房價跌 25%，你的頭期款就歸零了。**

> 🔧 **工程師視角**：這跟你在第 5 章學到的槓桿 ETF 是同一個機制——放大兩個方向。差別在於房子有居住價值、而且銀行通常不會因為房價跌就要你補錢（不像融資會被追繳）。但**槓桿的本質沒有改變**。

值得注意的是：**多數人一生中承擔過的最高槓桿，就是房貸**。而多數人從來沒意識到自己在用槓桿。

### 台灣房貸的三個實務重點

**重點 1：多數是機動利率。**

台灣的房貸多與定儲利率指數連動，**利率會隨央行政策調整**。這代表你的月付金**不是固定的**。

做壓力測試：**如果利率上升 1.5 個百分點，我的月付金會變多少？我還付得起嗎？** 一筆 1,200 萬、30 年期的貸款，利率從 2% 升到 3.5%，月付金會明顯增加。**買房前算這一題，不要用目前的利率算到剛好。**

**重點 2：寬限期是陷阱，也是工具。**

寬限期（只還息不還本，通常 1~3 年）能降低前期壓力，但：

- 寬限期內本金完全沒減少
- 寬限期結束後，剩餘本金要在更短的年限內還完 → **月付金會跳升**
- 很多人是用寬限期「買到超過負擔能力的房子」

**判準**：如果沒有寬限期你就買不起，那你買的是超過你能力的房子。

**重點 3：提前還款 vs 投資。**

判準跟第 1 章一樣，看利率：

```text
房貸利率 2%  vs  投資預期報酬 6%
  → 數學上不該提前還

但要加三個修正：
  1. 房貸利率是「確定的」，投資報酬是「不確定的」
  2. 機動利率可能上升，縮小這個價差
  3. 心理負擔是真實的成本
```

**一個折衷做法**：先確保緊急預備金充足、退休帳戶有在投入，然後把餘裕的錢分成兩份，一份還貸款、一份投資。這在數學上不是最優，但**它同時降低了兩種你不確定的風險**（利率上升、市場下跌），而且你會執行得下去。

## 四、買房如何改變你的資產配置

這是本章對你最實用的部分。

### 變化 1：你的資產結構會徹底翻轉

買房前後對照（以前面的例子）：

| | 買房前 | 買房後 |
| --- | --- | --- |
| 現金 | 500 萬 | 60 萬（頭期款 400 萬 + 交易成本與裝潢） |
| 股票 | 300 萬 | 300 萬 |
| **不動產** | **0** | **1,600 萬** |
| 負債 | 0 | **−1,200 萬** |
| **淨資產** | **800 萬** | **約 760 萬**（扣掉交易成本） |
| **不動產佔總資產比例** | 0% | **約 82%** |

**注意兩件事：**

1. **淨資產在買房當下是減少的**（交易成本、裝潢、稅費，通常是房價的 5%~10%）
2. **你的資產配置從「股票 37% / 現金 63%」變成「不動產 82% / 股票 15% / 現金 3%」**

你花了十四章決定的配置比例，**在買房的那一天全部作廢**。

### 變化 2：三重集中變成四重

第 0 章講的集中風險，買房後又多一層：

```text
你的薪水      ─┐
你的公司股票  ─┤
台股/科技業   ─┼─ 全部押在「台灣經濟」上
新台幣        ─┤
你的房子      ─┘  ← 而且它現在是最大的一塊，還帶 4 倍槓桿
```

而且**房價與就業市場正相關**——經濟差的時候，你可能同時面臨：房價跌、股票跌、公司裁員、房貸還要繳。

### 變化 3：緊急預備金的需求變大

買房後你的**固定支出**變高（房貸不能不繳），而且多了不可預期的修繕支出。

**買房後緊急預備金應該增加，而不是因為「錢都拿去付頭期款了」就縮水。** 這是很多人買房後最脆弱的地方——頭期款掏空了預備金，然後遇到一次熱水器加漏水加失業。

**規則**：頭期款**不可以**動用緊急預備金。如果動了，那代表你還不該買。

### 變化 4：金融資產的配置該怎麼調

這裡有兩種說法，都有道理，我把邏輯攤開讓你自己判斷：

**說法 A：買房後應該提高股票比例。**

理由：房子已經是你的「穩定資產」了（雖然它其實會波動），而且它佔比極高。你剩下的金融資產部位很小，時間也長，可以承擔更多風險。

**說法 B：買房後應該降低股票比例。**

理由：你現在有 1,200 萬的**固定負債**要還，現金流的容錯空間變小。而且房子本身是槓桿部位，整體風險已經很高，金融資產不該再加碼。

**我的看法**：

```text
買房後的頭幾年（負債高、現金薄）
    → 偏向 B：先把緊急預備金補回來，股票比例保守一些

房貸還了一段、預備金充足、現金流穩定後
    → 偏向 A：金融資產可以較積極，因為它是你唯一的
      「非不動產、非台灣、可以隨時變現」的部位

【共同的一條】
    → 金融資產應該**大幅偏向海外**，因為你的不動產、
      工作、貨幣已經 100% 在台灣了
```

最後那條是本章最重要的配置建議：**買房之後，你的股票部位更應該全球化，而不是繼續買台股。**

## 五、工程師特有的一個考量：地理流動性

這一點在一般理財書上不會講，但對你很重要。

**買房會把你釘在一個地點。** 而對工程師來說，換工作、跨城市、甚至出國，是薪資成長最大的來源之一（第 1 章講過，換工作的加薪幅度通常遠大於年度調薪）。

具體的衝突：

- 竹科的機會出現，但你在台北買了房
- 有一個很好的海外職缺，但你有房貸
- 公司要你外派兩年，房子要不要租出去？

**這不是說不能買房**，而是說：**買房的「隱性成本」包含你未來職涯選項的縮減**，而這個成本對高流動性的職業特別大。

**判斷方式**：問自己「未來十年，我有多大機率需要換城市工作？」機率高的話，把買房時點往後推、或選擇流動性較好（好賣好租）的房型，是合理的。

## 六、「買房抗通膨」對不對

**部分對。**

**對的部分**：房地產是實質資產，長期而言房價傾向跟隨通膨；而且房貸是**固定的名目負債**，通膨會侵蝕債務的實質價值——這對借款人有利。

**不完整的部分**：

1. **股票也是實質資產**，而且長期實質報酬通常更高
2. 房價的驅動因素不只通膨，還有利率、人口、政策、供給——**高通膨常伴隨升息，而升息會壓抑房價**（2022 年很多市場的經驗）
3. 你的房貸如果是**機動利率**，那「通膨侵蝕債務」的好處會被利率上升抵銷掉一部分

**所以**：抗通膨是買房的**其中一個**優點，但它不是一個獨立於價格的優點——**買貴了，抗通膨也救不了你。**

## 七、買房前的財務檢查清單

```text
【資金面】
□ 頭期款**沒有**動用緊急預備金
□ 除了頭期款，另外準備了房價 5%~10% 的交易成本與裝潢費用
   （仲介費、代書費、契稅、印花稅、規費、裝潢、家具、搬遷）
□ 買完之後，緊急預備金仍有 6~12 個月的**新的**支出水準
   （新的支出 = 房貸 + 管理費 + 稅 + 修繕準備）

【負擔面】
□ 房貸月付金佔家庭稅後月收入的比例，在可承受範圍
   （常見的保守建議是不超過三分之一，但要看你的其他支出）
□ **利率上升 1.5 個百分點的壓力測試通過**
□ 不需要靠寬限期才付得起
□ 假設「其中一人失業六個月」，仍然繳得出房貸

【比較面】
□ 我算過持有成本 vs 房租（含頭期款的機會成本）
□ 我知道這個區域的房價租金比大約是多少
□ 我誠實承認：如果房價不漲，這筆交易在財務上划不划算

【配置面】
□ 買房後我的不動產佔總資產的比例是 ____%
□ 我打算怎麼調整剩下的金融資產（尤其：要更全球化）
□ 我知道我現在有 __ 倍槓桿

【生活面】
□ 未來十年我需要換城市工作的機率大概是 ____
□ 我買房的主要理由是（財務 / 居住穩定 / 家庭需求）：______
```

**如果「負擔面」有任何一項打不了勾，那不是「再想想」，是「還不該買」。**

## 八、什麼時候「不買」是對的

誠實列出來，因為社會壓力會讓你覺得不買很奇怪：

- **房價租金比極高**（租金收益率 < 2%），而你不確定房價會繼續漲
- **你的職涯需要地理流動性**，未來十年很可能換城市
- **買了之後，房貸會讓你完全無法投資退休金**——這是用未來換現在
- **你買房的錢會讓不動產佔淨資產 90% 以上**，而且沒有其他緩衝
- **你只是因為「大家都買」「長輩說要買」而買**

**「租房」在財務上是一個完全正當的長期選擇**，前提是：**你要把「因為租房而省下來的錢真的投資出去」**。

這是關鍵的但書。租房者如果把省下的錢花掉了，那買房的強制儲蓄效果確實贏了——不是因為房子好，是因為紀律。而你讀完這本書、設好自動轉帳之後，紀律問題已經解決了。

## 九、已經有房的人，配置要怎麼調

如果你已經買了（或家裡有房會給你），做這四件事：

```text
1. 把房子用「保守的市價」列進資產負債表，房貸列進負債
   → 算出不動產佔淨資產的真實比例（多數人會嚇一跳）

2. 認知到你的「不動產 + 台灣 + 台幣」曝險已經極高
   → 金融資產的股票部位應該**大幅偏向海外**
   → 不要再買台灣的 REITs 或營建股（那是加碼不是分散）

3. 重算緊急預備金
   → 基準是「新的月支出」（含房貸、管理費、修繕準備）
   → 科技業建議 6~12 個月

4. 把房貸利率記進你的決策表
   → 提前還款 vs 投資，用第 1 章的利率分界判斷
   → 機動利率的話，每次央行調整後重新檢視一次
```

## 本章重點回顧

1. 房子有**消費品**與**投資品**雙重身分。正確的比較不是「房貸 vs 房租」，是**「持有成本 vs 房租」**——而持有成本必須包含**頭期款的機會成本**。
2. **房價租金比 > 30（租金收益率 < 3.3%）時，租房在財務上通常較划算**。台灣（尤其雙北）長期偏低，代表買房的財務報酬高度依賴房價繼續上漲。
3. **房貸是多數人一生中最高的槓桿**（頭期款兩成 = 4 倍）。房價跌 25%，頭期款歸零。
4. 台灣房貸三個實務重點：**多為機動利率**（要做升息 1.5pp 的壓力測試）、**寬限期是陷阱**（沒它就買不起 = 買太貴）、提前還款要看利率但也要看確定性與心理負擔。
5. **買房會讓你精心設計的配置在一天內作廢**：不動產可能瞬間佔到八成，且淨資產因交易成本而先減少。
6. 集中風險從三重變**四重**，而且房價與就業市場正相關——壞事會一起來。
7. **買房後最重要的配置調整：金融資產要大幅偏向海外**，因為你的房子、工作、貨幣已經 100% 在台灣。
8. 對工程師而言，買房的隱性成本包含**地理流動性的喪失**，而換城市/換工作是薪資成長的主要來源。
9. **「租房」是完全正當的長期選擇**，前提是省下來的錢真的投資出去——而你已經把紀律問題自動化解決了。
10. 檢查清單的「負擔面」有任一項打不了勾 → **不是再想想，是還不該買**。

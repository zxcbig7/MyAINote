# 指令新建SQL 角色

### User SQL

```sql
CREATE USER CANSON IDENTIFIED BY "1234"
DEFAULT TABLESPACE "USERS"
TEMPORARY TABLESPACE "TEOMP";
```

### ROLES

```sql
GRANT "CONNECT" TO <Role> WITH ADMIN OPTION;
GRANT "RESOURCE" TO <Role> WITH ADMIN OPTION;
```

### SYSTEM PRIVILEGES

```sql
GRANT DROP ANY TRIGGER TO <Role> WITH ADMIN OPTION;
GRANT ALTER ANY INDEX TO <Role> WITH ADMIN OPTION;
GRANT GREATE TRIGGER TO <Role> WITH ADMIN OPTION;
```

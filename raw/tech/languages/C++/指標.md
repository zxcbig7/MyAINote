# 指標

直接存取變數會對分配到的空間作存取，指標（Pointer）是一種變數，指標可儲存特定的記憶體位址

指標的概念算是讓 CPU 在存取資料時中間多一層的間接緩衝，為了增加程式的彈性

可以說：麻煩你到系辦找助教拿程式設計課程的講義

也可以說：麻煩你到系辦拿程式設計課程的講義

任意一種能夠記錄 "究竟是哪一個變數" 的方法理論上都可以用來做為指標，其實陣列變數的index就有指標的功能。

宣告指標，使用以下的語法：

```cpp
type *ptr;
```

- 說明
    
    ```cpp
    int* a;
    double* b;
    ```
    
    - 「*」 是一個單元 (unary) 的取值 (dereference or indirection) 運算子 (operator)，"將其後所接的運算式之數值算出， 當成一個記憶体位址， 並讀取該記憶体位址內 (適當格式) 之資料做為此運算之結果"。
    - a 稱為整數指標變數，b 稱為浮點指標變數。
    - 上面的定義是在定義 iPtr 為整數指標變數 (把 int* 看成是一種變數的型態)， 但是你也可以把它想像成是在定義 *iPtr 為整數， 如下：int (*iPtr)
        - 如此你更可以瞭解為什麼不另創一個型態叫做 intptr 來定義 iPtr 了。

---

### 使用指標變數

- 存放資料在指標變數內
    
    ```cpp
    int *iPtr;
    int x;
    iPtr = &x;// 存放位址資料到 iPtr 變數內
    ```
    
    - 「&」 是一個單元 (unary) 的運算符號
    - 功能是 "找出其後變數的位址， 做為該運算的結果"
    - 其後必須要是一個變數
- 讀取指標變數內資料
    
    ```cpp
    int* iPtr1, * iPtr2, * iPtr3;
    	int x, y;
    
    	iPtr1 = &x;
    	iPtr2 = &y;
    	iPtr3 = iPtr2;
    	
    	cin >> x >> y;
    
    	cout << iPtr1 << endl << iPtr2 << endl << iPtr3 << endl;
    ```
    
- 間接存取指標變數所指向資料變數內之資料
    
    * 運算子結合來 間接地存取資料變數內的資料
    
    ```cpp
    int* a;
    	int x = 10;
    
    	a = &x;
    
    	cout << "數值 : " << *a << endl;
    	cout << "位址 : " << a << endl;
    	
    	int y = *a * 10;
    
    	cout << "乘以10後 : " << y << endl;
    ```
    
    注意 : 定義 y 的兩個「*」意義不同
    

### 概念

---

- x = 10;
    
    "將 x 的位址找到， 以便在設定運算中存放等號右邊計算出來的數值"
    

- *iPtr1 = x;
    
    *iPtr1 放在等號右邊， 就是將變數 x 內存放的資料讀出
    
     *iPtr1 放在等號左邊，CPU 在由變數 iPtr1 中讀出變數 x 的位址後， 不去讀變數 x 內存放的資料， 而將該位址 (變數 x 之位址) 留下來準備在設定運算中存放等號右邊計算出來的數值。
    

出現 *iPtr1 的地方看成是一個變數

"iPtr1 變數內記錄的記憶體位址所代表的變數"

本來 x = 10; 這樣的敘述 在程式執行的過程中永遠只能在一個確定的變數 x 內存放 10 這樣的資料

現在 *iPtr1 = 10; 這樣的敘述則可以把 10 這個資料存放在很多不同的變數裡，完全看程式執行到這一列敘述時 iPtr1 這個變數裡存放著哪一個變數的位址來決定。

### 功能

---

1. 可以動態配置/釋放記憶體
2. 存取資料或是執行函式時有更多的彈性
    - 指標變數 (pointer variable) 來間接存取資料
    - 函式指標 (function pointer) 來間接呼叫函式
3. 製作有效率的資料結構 (串列、樹狀結構...)
4. 使用傳值 (call-by-value) 當作函式呼叫時參數傳遞的基本機制時， 傳遞一個指標進入函式的話， 可以讓函式裡直接更改主程式內的資料， 可以說是函式呼叫時另一種資料的傳遞方式。

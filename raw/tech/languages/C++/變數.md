# 變數

---

> 宣告變數
> 
- 變數名稱必須是**半形英數字**所組合而成的。
- 變數名稱不可以是**保留字**，像是`int`、`string`、`return`...

```cpp
變數型態 變數名稱(自訂);

變數型態 變數名稱(自訂) = 儲存值;

變數型態 變數名稱1, 變數名稱2, 變數名稱3...;
```

- 變數型態
    1. int：100、-5、1246 ...
        
        <aside>
        💡 整數型態能儲存範圍為 -2147483648 ~ 2147483647
        
        </aside>
        
    2. float：3.14159、4.3、-1.1 ...
    3. char：'a'、'R'、'1'、'@'、'*' ...
    4. string："Hello"、"^_^"、"Rock!" ...
    5. bool：`true`、`false`
- 範例：變數宣告
    
    ```cpp
    #include<iostream>
    using namespace std;
    
    int main()
    {
    
        int HP;
        int MP = 20;
    
        return 0;
    }
    ```
    
- 範例：多個變數宣告
    
    ```cpp
    #include<iostream>
    using namespace std;
    
    int main()
    {
        int HP, MP, EXP;
    
        return 0;
    }
    ```
    

> 輸出變數值
> 
- 只有在宣告變數時要打int，使用變數時不用打int。
- //代表註解，代表本列之後的部份被程式略過，只是給人看的注記。

**code**

```cpp
#include<iostream>
using namespace std;

int main()
{
    int HP = 100;

    cout << HP;            //<==== here

    return 0;
}
```

**output**

```cpp
100
```

> 指派
> 

```cpp
變數名稱 = 新的儲存值(運算式);
```

- 等號(=)是指派的意思，跟數學上的等號意義不同
- 左邊的變數內容　會變成　右邊的新的儲存值
- 舊的變數內容直接消失
- 範例
    
    code
    
    ```cpp
    #include<iostream>
    using namespace std;
    
    int main()
    {
        int like = 20;
    
        like = like + 1;             // <------ here
    
        cout << like << endl;
    
        return 0;
    }
    ```
    
    output
    
    ```cpp
    21
    ```
    
- 範例：多項式計算
    
    code
    
    ```cpp
    #include<iostream>
    using namespace std;
    
    int main()
    {
        int X = 10;
        cout << "When X=10 : " << X*(100-X)*(3*X+5) << endl;
    
        X = 30;
        cout << "When X=30 : " << X*(100-X)*(3*X+5) << endl;
    
        X = 100;
        cout << "When X=100 : " << X*(100-X)*(3*X+5) << endl;
    
        return 0;
    }
    ```
    
    output
    
    ```cpp
    When X=10 : 31500
    When X=30 : 199500
    When X=100 : 0
    ```
    

> 輸入變數值
> 

```cpp
cin >> 變數名稱;

cin >> 變數名稱1 >> 變數名稱2;
```

- 注意輸出 `<<` 和輸入 `>>` 的方向不一樣
- 執行時會看到 `_` 閃爍
- C++會幫我們略過輸入資料之間的空白、換行
- 範例
    
    **code**
    
    ```cpp
    #include <iostream>
    using namespace std;
    
    int main()
    {
        int priceA;
        int priceB;
        int priceTotal;
    
        cin >> priceA >> priceB;           // <==== here
    
        priceTotal = priceA + priceB;
    
        cout << priceTotal << endl;
    
        return 0;
    }
    ```
    
    **output**
    
    ```cpp
    100
    150
    250
    ```

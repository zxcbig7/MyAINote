# 基礎

> 基本架構
> 

```cpp
#include<iostream>
using namespace std;

int main()
{

    return 0;
}
```

- 循序執行： 將程式碼放入`{ }`中，就會由上到下執行。
- 結束：一旦執行到`return 0 ;`，程式就會立刻結束。
- 排版：在`{ }`內的東西利用 **Tab鍵** 向右推。

> 輸出文字
> 

```cpp
cout << "任意文字";

cout << "任意文字，輸出後換行" << endl;
```

- 句子的結尾要有 **分號** `;` ，代表一件事結束。
- `endl` 代表 end line，結束一行(換行)。

> 輸出運算式
> 

```cpp
cout << 運算式;
```

- 可以利用 ( ) 決定運算先後順序。
- 範例：運算式
    
    **Code**
    
    ```cpp
    #include<iostream>
    using namespace std;
    
    int main()
    {
        cout << 59+2 << endl;
    
        return 0;
    }
    ```
    
    **Output**
    
    ```cpp
    61
    ```
    
- 範例：輸出文字與運算式
    
    **Code**
    
    ```cpp
    #include<iostream>
    using namespace std;
    
    int main() {
      cout << "33 + 5 = " << 33+5 << endl;
      return 0;
    }
    ```
    
    **Output**
    
    ```cpp
    33 + 5 = 38
    ```
    

> 除法
> 

例如：7除以3 = ?

- 1.取商到整數位的除法(直接除) = 2
    
    **Code**
    
    ```cpp
    #include<iostream>
    using namespace std;
    
    int main()
    {
        cout << 7/3 << endl;
        return 0;
    }
    ```
    
    **Output**
    
    ```cpp
    2
    ```
    
- 2.精確到小數的除法(補小數位) = 2.3333
    
    **Code**
    
    ```cpp
    #include<iostream>
    using namespace std;
    
    int main()
    {
        cout << 7.0/3 << endl;
    		cout << 7/3.0 << endl;
        return 0;
    }
    ```
    
    **Output**
    
    ```cpp
    2.33333
    2.33333
    ```
    
- 3.輸出文字，沒有任何運算(文字顯示) = 7/3
    
    **Code**
    
    ```cpp
    #include<iostream>
    using namespace std;
    
    int main()
    {
        cout << "7/3" << endl;
        return 0;
    }
    ```
    
    **Output**
    
    ```cpp
    7/3
    ```
    

> 餘數  %
> 

**Code**

```cpp
#include<iostream>
using namespace std;

int main()
{

    cout << 23%3 << endl;
    cout << 23%5 << endl;
    cout << 23%7 << endl;

    return 0;
}
```

**Output**

```cpp
2
3
2
```

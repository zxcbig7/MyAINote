# 重複輸入

> while
> 

將輸入句 `cin >>` 放入 while中

注意：`cin` 該列的 分號 `;` **移除**後再放入小括號

```cpp
while( cin >> 變數 )
{
    每次輸入變數時，要做什麼事...
}

while( cin >> 變數1 >> 變數2 )
{
    每次輸入變數1、變數2時，要做什麼事...
}
```

- 範例：商品價錢和
    
    每一列輸入商品A和商品B的價錢，輸出價錢的和。
    
    輸入有若干列。
    
    code
    
    ```cpp
    #include<iostream>
    using namespace std;
    
    int main()
    {
        int A;
        int B;
    
        while( cin >> A >> B )
        {
            cout << A+B << endl;
        }
    
        return 0;
    }
    
    ```
    
    input
    
    ```cpp
    100 25
    100 150
    311246 25452
    1246 6421
    ```
    
    output
    
    ```cpp
    125
    250
    336698
    7667
    ```

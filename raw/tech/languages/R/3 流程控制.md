> if-else敘述
> 

if與else下方的程式碼必須要使用{}將程式碼包起來

若程式碼只有一行，可省略{}，但為閱讀方便，建議不要省略{}。

> 「if」、「else if」、「else」
> 

```r
score <-99
if(score >= 90){
  print("優秀")
}else if(score >= 60){
  print("及格")
}else{
  print("不及格")
}

[1] "優秀"
```

<aside>
💡 敘述是有順序的，若在if敘述判斷為真，就算後方else if判斷也為真，也只會執行if區段的程式碼

</aside>

> 巢狀if
> 

```r
CHscore <- 95
ENscore <- 55
if(CHscore >=60){
  if(ENscore >= 60){
    print("全部及格")
  }else{
    print("國文及格，英文再加油")
  }
}else{
  if(ENscore >= 60){
    print("英文及格，國文再加油")
  }else{
    print("全部不及格")
  }
}
```

> ifelse()
> 
- `ifelse(邏輯判斷,判斷為真要執行的程式碼,判斷為偽要執行的程式碼)`
- 可判斷向量，也就是可一次判斷多個元素

```r
score<-80
ifelse(score >= 60,"及格","不及格")
[1] "及格"

scoreVector <-c(100,23,46,77,86)
ifelse(scoreVector >= 60,"及格","不及格")
[1] "及格"   "不及格" "不及格" "及格"   "及格"
```

> while
> 

每次執行迴圈時檢查while邏輯判斷是否為TRUE

若邏輯判斷為TRUE，就會執行區段程式碼，若邏輯判斷為FALSE，則會結束迴圈執行。

```r
x <- 0
while(x <= 5){
  print(x)
  x <- x+1
}

[1] 0
[1] 1
[1] 2
[1] 3
[1] 4
[1] 5
```

> break 結束迴圈執行
> 

```r
for(n in 1:10){
  if(n==5){
    break ##一執行到5，跳出迴圈，不再執行之後的迴圈
  }
  print(n)
}

[1] 1
[1] 2
[1] 3
[1] 4
```

> next 跳過迴圈執行
> 

```r
for(n in 1:5){
  if(n==3){
    next
  }
  print(n)
}

[1] 1
[1] 2
[1] 4
[1] 5
```

# 4. 函數

# 撰寫函數（function）

---

函數的優點包括：

- 使程式碼更好理解
- 若需修改程式碼，若有搭配function的使用，只需要修改函數中的程式碼，其他部分則維持原有叫用函數方式即可
- 程式碼可以重複使用

> 函數組成
> 
- 名字 Function Name `function_name`
- 參數 Arguments, optional `arg_1, arg_2, ...`
- 程式碼本體 Function Body
- 回傳值 Return Value, optional `return_value`

```r
名字<-function(參數1,參數2,...){  
	程式碼本體
	最後一行的輸出自動設為回傳值
}
```

四個重要步驟:

1. 先寫出可以用的程式碼
2. 將程式碼內可以重複使用的部分指派給臨時變數
3. 其餘程式碼用臨時變數表示，讓程式碼變簡潔
4. 把程式碼變成函數function

```r
mymean <- function(vec){
  m<-sum(vec)/length(vec)
  return(m)
}

mymean(1:6)

[1] 3.5
```

```r
cube <- function(x){
  x_cube<-x*x*x
  return(x_cube)
}
cube(2:6)
```

> 函數命名原則
> 
- 長的函數名稱要遵循一樣的命名樣式
- 不要用原本就存在R中的函數名稱
- 通常是**動詞**

而參數也有對應的命名原則:

- 通常是**名詞**
- 輸入資料參數通常放在第一個
- 其他設定值通常會設定預設值

> 範例：BMI計算
> 

```r
bmi <- function(height,weight){
  if(height > 5){
    height <- (height/100)**2
  }else{
    print("error")
  }
  bmi <- weight/height
  return(bmi)
}

bmi(170,71)
[1] 24.56747
```

# 網路設定

---

## 基本指令

### 列出目錄內容

```bash
ls
ls -l  # 顯示詳細信息
ls -a  # 顯示所有文件，包括隱藏文件
```

### 變更當前工作目錄

```bash
cd /path/to/directory  # 進入指定目錄
cd ..  # 返回上級目錄
cd ~  # 返回主目錄
```

### 顯示當前工作目錄的絕對路徑

```bash
pwd
```

### 創建新目錄

```bash
mkdir new_directory
```

### 刪除空目錄

```bash
rmdir empty_directory
```

### 刪除文件或目錄

```bash
rm file_name  # 刪除文件
rm -r directory_name  # 刪除目錄及其內容
```

### 複製文件或目錄

```bash
cp source_file destination_file  # 複製文件
cp -r source_directory destination_directory  # 複製目錄
```

### 移動或重命名文件或目錄

```bash
mv old_name new_name  # 重命名
mv file_name /path/to/directory  # 移動文件
```

### 創建一個新的空文件或更新文件的時間戳

```bash
touch new_file
```

### 簡單易用的文本編輯器

```bash
nano file_name
```

### 連接文件並顯示其內容

```bash
cat file_name
```

### 分頁查看文件內容

```bash
less file_name
```

### 搜索文本文件中的指定模式

```bash
grep 'pattern' file_name
```

## 系統管理指令

以超級用戶權限執行命令

```bash
sudo command
```

## 用於包管理和軟件安裝

- `apt-get` 或 `apt`

```bash
sudo apt update  # 更新包索引
sudo apt upgrade  # 升級已安裝的包
sudo apt install package_name  # 安裝新包
sudo apt remove package_name  # 刪除包

```

### 顯示文件系統磁盤空間使用情況

```bash
df -h
```

### 檢查文件和目錄的磁盤使用情況

```bash
du -h
du -sh directory_name  # 檢查目錄大小
```

### 顯示當前運行的進程

```bash
ps aux
```

### 實時顯示系統運行狀態，包括CPU和內存使用情況

```bash
top
```

### 終止進程

```bash
kill process_id
kill -9 process_id  # 強制終止
```

### 更改文件或目錄的權限

```bash
chmod 755 file_name
```

### 更改文件或目錄的所有者

```bash
sudo chown user:group file_name
```

### 配置和顯示網絡接口

```bash
ifconfig
ip addr show
```

## 壓縮和解壓縮指令

### 創建和提取tar檔案

```bash
tar -cvf archive.tar directory  # 創建tar檔案
tar -xvf archive.tar  # 解壓tar檔案
tar -czvf archive.tar.gz directory  # 創建gzip壓縮的tar檔案
tar -xzvf archive.tar.gz  # 解壓gzip壓縮的tar檔案
```

### 創建和解壓zip檔案

```bash
zip -r archive.zip directory  # 創建zip檔案
unzip archive.zip  # 解壓zip檔案
```

# 四種筆記類群

* **名詞筆記(#📖)**：專門寫名詞解釋的筆記
* **來源筆記(#📥)**：來自於外界的知識所做的筆記
* **關係筆記(#🔗)**：自己思考後寫下的筆記
* **主題筆記(#🗺)**：能夠囊括同主題內容的筆記，也稱為 Map of Content (縮寫為MOC) 筆記

學習一項新事物時，會先從整理名詞筆記開始，接著閱讀其他人寫的資料整理來源筆記、自己想過一遍後寫下對事物的理解 （關係筆記），而這些筆記都可以歸類到某個主題之下（主題筆記）。

| **每一篇筆記只會標上這 4 種中的一種**


# 四種筆記形式

* Fleeting note (靈感筆記)：用來捕捉瞬間出現的靈感，重點是「紀錄」，而不考慮內容的完整性。
> **_如果筆記未經整理，其實就是一堆沒用的訊息。_**
* Permanent note (永久筆記)：將 Fleeting note 重新組織、整理、連結過後的筆記，通常能是一個邏輯完整的段落。

> **萬能寫作法**
>>- 觀點：我想說什麼
>>- 案例：為什麼我會這樣說，舉 1–3 個例子來佐證
>>- 總結：因為這個主題，我的感覺是什麼

>>  可以想：「如果今天有人影印這篇筆記，他能夠光看內容就知道一件事情的來龍去脈嗎？」來檢驗 Permanent note 是否寫的完整

>> 任何的文章 (Article) 都由無數篇 Permanent note 所構成。

* Literature note (讀書筆記)：藉由閱讀某個外部資料產生筆記

* Project-related note (專案筆記)：
** 專案是指一個特殊而有一定限度的 (Finite)任務，或由一群聚相互關連性的工作所共同組合起來的任務，而該任務是以獲得特殊結果或圓滿達成某種成就為目標。
- 有「開始時間」跟「結束時間」
- 有相似性質的任務組合而成，跟專案相關的筆記都會被保存在一個資料夾中
- 為了達成某種目標，專案結束後筆記就會封存掉

如何知道何時要建立一個 Project-related note 的資料夾？」
- 從上到下 (Top-down)：資料夾，將相關的資料、筆記都丟在裡面。
- 從下到上 (Bottom-up)：自由的記錄筆記，一邊觀察筆記的內容交集。

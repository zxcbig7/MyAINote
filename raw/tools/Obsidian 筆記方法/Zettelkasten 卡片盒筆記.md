# Zettelkasten 卡片盒筆記

## 是什麼

德國社會學家 **Niklas Luhmann** 提出的筆記法。Luhmann 40 年研究生涯出版 70+ 本書、400+ 篇論文，跨足社會學、生物學、數學，他自己歸功於 Zettelkasten。

詞源：德文 **Zettel**（卡片/紙條） + **Kasten**（盒子）。

> 核心精神：**筆記與筆記之間的「連結」才是有效的關鍵**，不是分類、不是收藏。

## Luhmann 的實際操作

每有一個想法：

1. 立刻寫在新卡片上：關鍵字 + 闡述 + 例子
2. 翻找盒中相關舊卡片
3. 在新卡片上寫下相關卡片的索引編號（例如 `1`、`1/1`、`1/1a`）
4. 連結回去，雙向可達

長期下來形成一張**網狀知識圖**，而不是線性筆記本。

例如：卡片盒筆記法/在卡片上加入索引並建立筆記連結/社會學與生物學。在每一張卡片上會寫上與此筆記相關卡片的索引編號，例如1.點子A與1/1點子D，下方為示意圖。

可以使用標籤(tag)來解決問題，一則記事可以同時有兩個以上的標籤，這樣一則筆記就可以同時被分類成多個主題了。標籤幫助我們解決筆記定位的問題。

## 核心原則（12 條）

1. **原子化**：一則筆記只記一件事
2. **獨立性**：單獨讀就讀得懂，可自由移動、合併
3. **建立連結**：每則新筆記都要連到舊筆記
4. **註解連結**：寫清楚「為什麼連這則」
5. **用自己的話**：禁止複製貼上
6. **記下來源**：避免侵權，方便回溯
7. **加入自己的觀點**：不只是抄寫
8. **別擔心結構**：放掉「組織」的執念
9. **加入連結頁**：把相關筆記串成一篇短文
10. **加入總目錄頁（Index / MOC）**：給「Epic」級主題一個入口
11. **不刪舊筆記**：用新筆記補充說明舊的不足
12. **盡情寫**：先記再說

## 軟工視角的類比

> 一則筆記只寫一個想法 ≈ 一個 function 只做一件事

**單一職責原則**讓管理變單純。Zettelkasten 是把這個原則套到知識管理上。

## 跟其他筆記法的差異

- **康乃爾、麥肯錫筆記法**：是「工具」，用來整理一篇/一場資料
- **Zettelkasten**：是「方法論」，教你怎麼用工具
- **子彈筆記**：仍侷限於本子的頁與頁；Zettelkasten 直接打破本子框架

# 新建傳案

> dotnet new console 新建專案
> 

> (**NET 7.0 版本如果需要建立原始的專案需要用)**
dotnet new console --use-program-main
> 

> dotnet run 執行專案
> 

```csharp
using System;

namespace Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello World!");
        }
    }
}

// 註釋
```

> 藍色字 `using` `namespace` `class` `static` `void` `string` 為保留字
> 

> `System` `Console` `WriteLine`是程式庫 .NET 中的識別字
> 

> `Demo` `Prgram` `Main` `args`是自行定義的識別字
> 

<aside>
💡 Main() 是 C# 程式執行的預設起點，如果類別 (class) 中沒有定義 Main() ， C# 的驅動器 (driver) dotnet 指令便無法執行程式。

</aside>

以上code的流程說明

1. 引入 .NET 程式庫
    
    ```csharp
    using System;
    ```
    
2. 定義命名空間 (namespace) `Demo` 
    
    ```csharp
    namespace Demo
    {
        // 命名空間的內容
    }
    ```
    
3. 定義類別 `Program` 
    
    ```csharp
    class Program
    {
        // 類別的內容
    }
    ```
    
    > 類別名稱 Program 依習慣跟檔案名稱 Program.cs 相同。
    > 
4. 定義 **`static`** 的 `Main()` 方法 (method)
    
    ```csharp
    static void Main(string[] args)
    {
        Console.WriteLine("Hello World!");
    }
    ```

## **switch**

```csharp
int caseDemo = 3;
switch (caseDemo)
{
    case 1:
        Console.WriteLine("選項1");
        break;
    case 2:
        Console.WriteLine("選項2");
        break;
    case 3:
        Console.WriteLine("選項3");
        break;
    default:
        Console.WriteLine("預設選項");
        break;
}
```

> 其中 **switch**、 **case、 default** 是關鍵字
> 

<aside>
❗ 1. **switch** 後面的小括弧是常數值
2. 每個 **case** 的常數後都要接冒號
3. 關鍵字 **switch** 之後的小括弧可以是預算式，由運算式的計算結果來當 **case**
 判斷的值， C# 7.0 之後接受參考型態的物件，但不能是 **null**。

</aside>

> **case** 底下的陳述，習慣上沒有用大括弧，而是用縮排 (indentation) 。
> 

> 每個 **case**最後，都有加上 **break** 陳述 (break statement) ，這是中斷跳出執行的意思。
表示這個 **case** 符合並且執行了 **case** 所屬的工作，到此跳出 **switch-case** 的範圍，程式繼續執行 **switch** 大括弧後的陳述。
> 

> **default** 跟 **if-else if-else** 最後的 **else** 的用法相同。
**如果 case 後沒有 break ，每一次執行 default 都會被執行。**
>

# 陣列(array)

- 每一筆資料稱之為元素 (element)
- 元素必須是相同的資料型態 (data type)

> 宣告陣列需要使用型態名稱及中括弧，然後用關鍵字 **new** 與型態名稱加上中括弧，中括弧裡頭要放入元素數量
> 

```csharp
//用關鍵字 new 宣告建立整數陣列，裡頭每一個元素會初始化為 0
int[] a = new int[5];

//用大括弧設定陣列元素
int[] b = new int[5] {1, 2, 3, 4, 5};

//以上可以少掉 new 的部分，簡寫如下
int[] c = {1, 2, 3, 4, 5};
```

用 **for** 迴圈 (loop) 替陣列元素設值，然後再用 **foroeach…in…** 迴圈逐一取出元素，印在命令列上

```csharp
int[] a = new int[5];
int value = 1;
for (int i = 0; i < 5; i++)
{
   a[i] = value++;
}

//變數 i 會逐一取得整數陣列變數 a 當中的元素，所以變數 i 必須宣告為整數。
foreach (int i in a)
{
    Console.WriteLine(i);
}

//最後會逐行列印出1,2,3,4,5
```

# **列舉與結構**

- 列舉是一組用識別字定義的整數常數

> Day 是列舉，裡頭的 Sun 等同於整數 0 ，之後逐次遞增 1
（Mon 等同於整數 1 ， Tue 等同於整數 2，以此類推）
> 

```csharp
using System;

namespace EnumDemo01
{
    class Program
    {
        enum Day {Sun, Mon, Tue, Wed, Thu, Fri, Sat};

        static void Main(string[] args)
        {
            int a = (int) Day.Sun;
            int b = (int) Day.Thu;
            Console.WriteLine("Sunday: {0}", a);
            Console.WriteLine("Thursday: {0}", b);
        }
    }
}
```

實際使用列舉，需要進行型態轉換

1. 從列舉 Day 中取出 Sun 與 Thu 
2. 把這兩個印出來，注意取出必須加上**小括弧及型態名稱**，進行強制型態轉換

> 列舉中的常數可以是任何的整數型態，預設是 **int**，其他都要宣告
> 

```csharp

using System;

namespace EnumDemo02
{
    class Program
    {
        enum Range: long {Max=2000000000L, Min=1000000000L};
				//注意整數字面常數 (literal) 最後面的 L 表示這是 long 型態

        static void Main(string[] args)
        {
            long a = (long) Range.Max;
            long b = (long) Range.Min;
            Console.WriteLine("Max: {0}", a);
            Console.WriteLine("Min: {0}", b);
        }
    }
}
```

> 列舉通常會用在需要常數識別字的地方，結構則是簡單的類別 (class)

# ? vs. ??

```csharp
//A.比如下面一句，直接定義int爲null是錯誤的，錯誤提示爲無法將null轉化成int。
//  因爲後者是不可以爲null的值類型。
private int getNum = null;

//B.如果修改爲下面的寫法就可以初始指爲null，在特定情況下?等同於基礎類型爲Nullable。
private int? getNum = null;
private Nullable<int> getNumNull = null;
```

```csharp
//A.需要if語句來判斷，當Request.Params["para"]不爲null時，取出para的值。
string strParam = Request.Params["para"];  
if ( strParam == null )  
{  
   strParam = "";  
}   

//B.用三元運算符?簡化寫法，取出para的值。
string strParam=Request.Params["para"] == null ? "":Request.Params["para"];
```

> ?? 運算符稱爲 null 合併運算符，用於定義可以爲 null 值的類型和引用類型的默認值。
**如果此運算符的左操作數不爲 null，則將return左操作數；否則return右操作數。**
> 

```csharp
//A.定義getNum爲null，輸出結果爲0
private int? getNum = null;
Console.WriteLine(getNum ?? 0);

//B.定義getNum爲1，輸出結果爲1
private int getNum = 1;
```

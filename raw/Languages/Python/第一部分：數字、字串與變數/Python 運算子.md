# Python 運算子

| 運算子 | 說明 | 範例 | 結果 |
| --- | --- | --- | --- |
| `+` | 加法 | `5 + 8` | `13` |
| `-` | 減法 | `8 - 5` | `3` |
| `*` | 乘法 | `4 * 3` | `12` |
| `/` | 除法（浮點） | `7 / 2` | `3.5` |
| `//` | 除法（小數捨去） | `7 // 2` | `3` |
| `%` | 餘數（模數） | `7 % 3` | `1` |
| `**` | 乘冪 | `3 ** 4` | `81` |

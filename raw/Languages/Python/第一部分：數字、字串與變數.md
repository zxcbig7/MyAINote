# 第一部分：數字、字串與變數

## Python 有以下四個內建的資料類型:

- 布林 ( 值有True or False )
- 整數 ( 1,2,3 )
- 浮點數 ( 3.14159 , 1.0e8 或者一乘十的八次方 10000000.0 )
- 字串

---

## 在Python，使用  = 來指派一個值給變數

```python
>>> a = 7
>>> print(a)
7
```

## 利用 type(物件) 得知該物件的資料類型

- 範例 :
    
    ```python
    >>> type(87)

    >>> type(9.9)

    >>> type('abc')

    ```
    

在Python，類別( class )與類型( type )幾乎相同。

## 基數

- 二進位(基數2) : 用 0b 或者 0B 表示
- 八進位(基數8) : 用 0o 或者 0O 表示
- 十六進位(基數16) : 用 0x 或者 0X 表示
- 範例 :
    
    >>> 0b10
    2
    >>> 0o10
    8
    >>> 0x10
    16

## 類型轉換

- 使用 int( ) 函式，會保留整數，捨棄小數部分。
    - 範例(布林，浮點數，字串包函正負)
        
        ```python
        >>> int(True)
        1
        >>> int(False)
        0
        #-----------------
        >>> int(98.6)
        98
        >>> int(1.0e8)
        100000000
        #-----------------
        >>> int('99')
        99
        >>> int('-89')
        -89
        >>> int('+35')
        35
        ```
        
    - ❗ int( )無法處理有小數點及指數的字串
        
        ```python
        >>> int('9.8')
        Traceback (most recent call last):
          File "<pyshell#20>", line 1, in <module>
            int('9.8')
        ValueError: invalid literal for int() with base 10: '9.8'
        ```
        
- 使用 floa( ) 函式，將其他類型轉成浮點數。
    - 範例(布林，整數，字串包函正負)
        
        ```python
        >>> float(True)
        1.0
        >>> float(False)
        0.0
        
        >>> float(99)
        99.0
        
        >>> float('-88.6')
        -88.6
        ```
        
- 使用 str( ) 函式，將其他類型轉成字串。
    - 範例
        
        ```python
        >>> str(-98.6)
        '-98.6'
        
        >>> str(1.0e4)
        '10000.0'
        
        >>> str(True)
        'True'
        ```
        
- 使用 引號 建立字串類型。
    - 範例 1 ( ' ' 以及 " " 框住字串 )
        
        ```python
        >>> 'snap'
        'snap'
        >>> "cookie"
        'cookie'
        ```
        
    - 範例 2 (在一種引號裡面用另外一種引號)
        
        ```python
        >>> "'Nay,' said the naysayer."
        "'Nay,' said the naysayer."
        
        >>> '"Nay," said the naysayer.'
        '"Nay," said the naysayer.'
        ```
        
    - 範例 3 ( 3個引號建立多行字串 )
        
        ```python
        >>> a = '''line 1
        line 2
        line 3
        line 4'''
        
        >>> print(a)
        line 1
        line 2
        line 3
        line 4
        
        >>> a
        'line 1\nline 2\nline 3\nline 4'
        ```
        
        說明 : /n 是轉義字元

## 其他功能

- **利用反斜線( \ )轉義，賦予特殊含義**
    - /n 表示新的一行
        
        ```python
        >>> a = "A man,\nA plan,\nA canal:\nPanama."
        >>> print(a)
        A man,
        A plan,
        A canal:
        Panama.
        >>> a
        'A man,\nA plan,\nA canal:\nPanama.'
        ```
        
    - /t (tab) 來對齊文字
        
        ```python
        >>> print("a\tbc")
        a	bc
        
        >>> print("ab\tc")
        ab	c
        ```
        
    
- **用 + 來結合字串**
    - '字串' + '字串'
        
        ```python
        >>> 'abc'+'zxc'
        'abczxc'
        ```
        
    - '字串'  '字串'
        
        ```python
        >>> 'zxczxc''aaa'
        'zxczxcaaa'
        ```
        
    - 字串變數 + 字串變數
        
        ```python
        >>> a = 'Duck.'
        >>> b = a
        >>> c = 'Grey Duck!'
        
        >>> a + b + c
        'Duck.Duck.Grey Duck!'
        
        >>> print(a, b, c)
        Duck. Duck. Grey Duck!
        ```
        
        補充 : print( )會在每一個引數之間自動加空格
        
    
- **用 * 來複製字串**
    - 範例
        
        ```python
        >>> start = 'Na '*4 + '\n'
        >>> middle = 'Hey'*3 + '\n'
        >>> end = 'Goodbye.'
        
        >>> print(start+start+middle+end)
        Na Na Na Na 
        Na Na Na Na 
        HeyHeyHey
        Goodbye.
        ```
        

- **用 [ ] 來擷取字元**
    - 用位移值 0 指定最左邊， -1 指定最右邊
        
        ```python
        >>> letters = 'abcdefghijklmnopqrstuvwxyz'
        >>> letters[0]
        'a'
        >>> letters[-1]
        'z'
        >>> letters[5]
        'f'
        ```
        
    - ❗ 不能用來更改字串文字
        
        ```python
        >>> name = 'Petty'
        >>> name[0] = H
        Traceback (most recent call last):
          File "<pyshell#81>", line 1, in <module>
            name[0] = H
        NameError: name 'H' is not defined
        ```
        
    
- **用 replace( ) 或者 *slice* 來替換字串內的文字**
    
    ```python
    >>> name = 'Penny'
    >>> name.replace('P','H')
    'Henny'
    
    >>> "L"+name[1:]
    'Lenny'
    ```
    

- **使用 [ 開始 : 結束 : 間格 ] 的 Slice 擷取子字串**
    - [ : ] 會擷取整個序列，從開始到結束
    - [ *start* : ] 從指定的 *start* 到結束
    - [ : *end* ] 從開始到指定的 *end* 減1
    - [ *start* : *end* ] 從指定的 *start* 到 *end* 減1 結束
    - [ *start* : *end* : *step*] 從 *start* 到 *end* 減1, 跳過 *step* 字元
        
        注：end 要 - 1 理由是因為開頭是 0
        
        - 範例 :
            
            ```python
            >>> letters = 'abcdefghijklmnopqrstuvwxyz'
            >>> letters[:] //全部
            'abcdefghijklmnopqrstuvwxyz'
            >>> letters[20:] #20到最後
            'uvwxyz'
            >>> letters[12:15] //12到14**(15-1)**
            'mno'
            >>> letters[-3:] #最後三個
            'xyz'
            
            >>> letters [::7]
            'ahov'
            
            >>> letters [-1::-1] #反向呈現
            'zyxwvutsrqponmlkjihgfedcba'
            >>> letters [::-1]
            'zyxwvutsrqponmlkjihgfedcba'
            ```
            
- **用 len( )來取得長度**
    
    ```python
    >>> letters = 'abcdefghijklmnopqrstuvwxyz'
    >>> len(letters)
    26
    ```
    
- **用 split( ) 來分割**
    - 方框裡面有值時，把該值當分割點
        
        ```python
        >>> todos = 'get gloves,get mask,give cat vitamins,call ambulance'
        >>> todos.split(',')
        ['get gloves', 'get mask', 'give cat vitamins', 'call ambulance']
        ```
        
    - 方框裡面沒有值時，分割點為空白字元(空格字元，換行字元，)
        
        ```python
        >>> todos = 'get gloves,get mask,give cat vitamins,call ambulance'
        >>> todos.split()
        ['get', 'gloves,get', 'mask,give', 'cat', 'vitamins,call', 'ambulance']
        ```
        
- **用join( )來結合**
    
    可以說是 split( ) 的相反
    
    - 用法: *字串.join(串列)*
        
        ```python
        >>> crypto_list = ['Yeti','Bigfoot','Loch Ness Monster']
        >>> crypto_string = ', '.join(crypto_list)
        >>> crypto_string
        'Yeti, Bigfoot, Loch Ness Monster'
        >>> print('Found that singing book deals:',crypto_string)
        Found that singing book deals: Yeti, Bigfoot, Loch Ness Monster
        
        >>> crypto_string = '\n '.join(crypto_list)
        >>> print('Found that singing book deals:'crypto_string)
        Found that singing book deals: Yeti
         Bigfoot
         Loch Ness Monster
        ```

- **字串內容 判定 與 檢查**
    
    ```python
    >>> test = 'abcdefasdhzklxvzxkcxcjsgh'
    
    >>> test.startswith('a') #開頭是否為該字串
    True
    >>> test.endswith('gh') #結尾是否為該字串
    True
    
    >>> test.find('c') #找字串首先出現的位移值(從0開始)
    2
    >>> test.rfind('c') #找字串最後出現的位移值(從0開始)
    20
    
    >>> test.count('c')  #該字串出現幾次
    3
    
    >>> test.isalnum() #是否只有字母與數字
    True
    ```

- **大小寫 與 對齊**
    - 大小寫
        
        ```python
        >>> setup = 'a duck goes into a bar...'
        
        >>> setup.strip('.') #移除兩端 . 序列
        'a duck goes into a bar'
        
        >>> setup.capitalize() #第一個字母大寫
        'A duck goes into a bar...'
        >>> setup.title() #所有單字第一個字母大寫
        'A Duck Goes Into A Bar...'
        >>> setup.upper()  #全大寫
        'A DUCK GOES INTO A BAR...'
        >>> setup.lower() #全小寫
        'a duck goes into a bar...'
        >>> setup.swapcase() #大小寫交換
        'A DUCK GOES INTO A BAR...'
        ```
        
    - 對齊
        
        ```python
        >>> setup.center(30) #30個空格中 向中對齊
        '  a duck goes into a bar...   '
        
        >>> setup.ljust(30) #靠左
        'a duck goes into a bar...     '
        
        >>> setup.rjust(30) #靠右
        '     a duck goes into a bar...'
        ```
        
- 用 replace()來替換
    
    ```python
    >>> setup = 'a duck goes into a bar...'
    
    >>> setup.replace('duck','marmoset')
    'a marmoset goes into a bar...'
    
    >>> setup.replace('duck','marmoset',100)
    'a marmoset goes into a bar...'
    ```
    
    如果後面不加數字的話，只會變動第一個。

### 什麼是True? 什麼是False?

- 以下例子會被視為 False
    1. 布林 → False
    2. null → None
    3. 整數零 → 0
    4. 浮點數零 → 0
    5. 空字串 → ''
    6. 空串列 → []
    7. 空tuple → ()
    8. 空字典 → {}
    9. 空集合 → set()

- 所有其他東西都會被視為 True
    1. 布林 → True
    2. 整數 → 2
    3. 浮點數 → 87.55
    4. 字串 → '我很廢'
    5. 串列 → ['a','b','c']
    6. tuple → ('d','e','f')
    7. 字典 → {'a':'apple','b':'ball'}
    8. 集合 → set(1,3,5,7,9)

```python
>>> some_list = []
>>> if some_list:
    print('There is something.')
else:
    print("It's empty.")
```

# 用 for 來迭代

- 逐一查看序列
    - **用 for 方式(比較簡單)**
        
        ```python
        >>> rabbits = ['Flopsy','Mospy','Cottontail','Peter']
        >>> for rabbit in rabbits:
            print(rabbit)
            
        
        Flopsy
        Mospy
        Cottontail
        Peter
        ```
        
    - **用 While 方式**
        
        ```python
        >>> rabbits = ['Flopsy','Mospy','Cottontail','Peter']
        >>> current = 0
        >>> while current < len(rabbits):
            print(rabbits[current])
            current += 1
        
            
        Flopsy
        Mospy
        Cottontail
        Peter
        ```
        
- **迭代與各種型態資料的應用**
    - **迭代tuple 或串列時。**
        - 只會產生一個項目
        
        ```python
        >>> tuple_list = (1,2,3)
        >>> for number in tuple_list:
            print(number)
        
            
        1
        2
        3
        ```
        
    - **迭代字串時。**
        - 只會生產一個字元
        
        ```python
        >>> word = 'cat'
        >>> for letter in word:
            print(letter)
        
        c
        a
        t
        ```
        
    - **迭代字典時。**
        - 用 keys() 回傳 Key ←預設
        - 用 values() 回傳 value
        
        ```python
        >>> accusation = {'room':'ballroom','weapen':'lead pipe',
                      'person':'Col. Mustard'}
        
        >>> for card in accusation:    #或 for card in accusation.keys():
            print(card)
        
        room
        weapen
        person
        >>> for card in accusation.values():    #回傳 value
            print(card)
        
            
        ballroom
        lead pipe
        Col. Mustard
        
        #用Tuple迭代Key與Value，可以用items()
        >>> for item in accusation.items():
            print(item)
        
            
        ('room', 'ballroom')
        ('weapen', 'lead pipe')
        ('person', 'Col. Mustard')
        ```

### 用zip()來迭代多個序列

- **程式碼**
    
    ```python
    >>> days = ['Monday','Tuesday','Wednesday']
    >>> fruits = ['banana','orange','peach']
    >>> drinks = ['coffee','tea','bear']
    >>> desserts = ['tiramisu','ice cream','pie','pudding']
    >>> for day,fruit,drink,dessert in zip(days,fruits,drinks,desserts):
        print(day,': drink ',drink,'- eat',fruit,'- enjoy',dessert)
    
    Monday : drink  coffee - eat banana - enjoy tiramisu
    Tuesday : drink  tea - eat orange - enjoy ice cream
    Wednesday : drink  bear - eat peach - enjoy pie
    
    >>>
    ```
    
    <aside>
    💡 因為以最少的序列結束時停止，所以沒有第四天的pudding
    
    </aside>
    
- zip 應用
    - **逐一查看多個序列，並將同一個位移值的項目做成Tuple**
        
        ```python
        #建立英語和法語的tuple
        >>> english = 'Monday','Tuesday','Wednesday'
        >>> french = ('Lundi','Mardi','Mercredi')
        
        #以迭代方式儲存tuple
        >>> list(zip(english,french))
        [('Monday', 'Lundi'), ('Tuesday', 'Mardi'), ('Wednesday', 'Mercredi')]
        
        #建立簡易英法字典
        >>> dict(zip(english,french))
        {'Monday': 'Lundi', 'Tuesday': 'Mardi', 'Wednesday': 'Mercredi'}
        >>>
        ```

### 用 range() 來產生數字序列

range()會回傳指定範圍內的一串數字

- 用法類似 slice : range( start, stop, step )
- 忽略 start 會從 0 開始
- stop 是唯一必要的值，**最後一個生產的值在 stop 的前一個**
- step 預設為 1，也可以用 -1 往回走
- **程式碼**
    
    ```python
    >>> for x in range(0,3):
        print(x)
    
    0
    1
    2
    >>>
    
    >>> list(range(0,11,2))
    [0, 2, 4, 6, 8, 10]
    ```

# 生成式

生成式 : 以一個或多個迭代器來建立資料結構的方式。可藉由生成式結合迴圈與條件測試式簡化程式碼。

### 1. 串列生成式 :

- 建立串列生成式 : [ 運算式 for 項目 in 可迭代項目 ]
    - 過去的寫法(過去練習都慢慢打，沒有效率)
        1. 個別新增
            
            ```python
            >>> number_list = []
            >>> number_list.append(1)
            >>> number_list.append(2)
            >>> number_list
            [1, 2]
            ```
            
        2. 化簡1_用迭代器與range()
            
            ```python
            >>> number_list = []
            >>> for number in range(1,4):
                number_list.append(number)
            [1, 2, 3]
            ```
            
        3. 化簡2_用list()與range()
            
            ```python
            >>> number_list = []
            >>> number_list = list(range(1,5))
            >>> number_list
            [1, 2, 3, 4]
            ```
            
    1.  串列生成式 : [ 運算式 for 項目 in 可迭代項目 ]
        
        ```python
        >>> number_list = [number for number in range(1,7)]
        >>> number_list
        [1, 2, 3, 4, 5, 6]
        
        >>> number_list = [number-1 for number in range(1,7)]
        >>> number_list
        [0, 1, 2, 3, 4, 5]
        ```
        
    2. 串列生成式_加條件 : [ 運算式 for 項目 in 可迭代項目 if 條件式 ]
        
        ```python
        >>> a_list = [number for number in range(1,6) if number % 2 == 1]
        >>> a_list
        [1, 3, 5]
        
        >>> a_list = []
        >>> for number in range(1,6):
            if number % 2 == 1:
                a_list.append(number)
        
        >>> a_list
        [1, 3, 5]
        ```
        
    3. 補充 
        - 1 : 巢狀迭代
            
            ```python
            >>> rows = range(1,4)
            >>> cols = range(1,2)
            >>> for row in rows:
                for col in cols:
                    print(row,col)
            
                    
            1 1
            2 1
            3 1
            ```
            
        - 2 : 巢狀迭代建立T
            
            ```python
            >>> rows = range(1,4)
            >>> cols = range(1,2)
            
            >>> cells = [(row,col) for row in rows for col in cols]
            
            >>> for cell in cells:
                    print(cell)
            
                    
            (1, 1)
            (2, 1)
            (3, 1)
            ```
            
        - 3 : Tuple也是**可迭代項目**
            
            ```python
            >>> rows = range(1,4)
            >>> cols = range(1,2)
            
            >>> cells = [(row,col) for row in rows for col in cols]
            
            >>> for row, col in cells:
                    print(row,col)
            
                    
            1 1
            2 1
            3 1
            ```

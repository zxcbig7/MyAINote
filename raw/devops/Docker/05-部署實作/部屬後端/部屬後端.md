# 部屬後端

## Docker 部署常用指令

### 登入

```bash
# 登入 Azure
az login
# Tenant 失敗的時後看Log裡面的內容輸入
az login --tenant <Tenant Value>

# 看azure 帳號
az account list --output table

# 登入 Azure Container Registry
# <ACR名稱>: Azure Container Registry 名稱
az acr login --name <ACR名稱>

# 登入 Docker Hub
docker login
```

---

### Image 操作

> 電腦記得開 Docker
> 

```bash
# Step1: 本地端 Build image
docker build -t <image名稱>:<tag> .

# Step2: Tag image（準備推到 ACR）
docker tag <本機image> <ACR>.azurecr.io/<image名稱>:<tag>

# Step3: Push 到 ACR
docker push <ACR>.azurecr.io/<image名稱>:<tag>

# ==== 其他可能有用的 Docker 指令 ====
# 列出本機所有 image
docker images

# 刪除 image
docker rmi <image名稱>:<tag>

# Pull image
docker pull <ACR>.azurecr.io/<image名稱>:<tag>
```

---

### Container 操作

```bash
# 跑 container（背景執行）
docker run -d -p 8080:8080 --name <container名稱> <image名稱>:<tag>

# 跑 container（帶環境變數）
docker run -d -p 8080:8080 \
  -e ASPNETCORE_ENVIRONMENT=Production \
  -e ConnectionStrings__Default="Server=..." \
  --name <container名稱> <image名稱>:<tag>

# 列出執行中的 container
docker ps

# 列出所有 container（含停止的）
docker ps -a

# 停止 container
docker stop <container名稱>

# 刪除 container
docker rm <container名稱>

# 看 container log
docker logs <container名稱>

# 進入 container 內部（debug 用）
docker exec -it <container名稱> /bin/bash
```

### ACR 管理

```bash
# 列出 ACR 裡的 repository
az acr repository list --name <ACR名稱> --output table

# 列出某個 repository 的所有 tag
az acr repository show-tags --name <ACR名稱> --repository <image名稱> --output table

# 刪除某個 image
az acr repository delete --name <ACR名稱> --image <image名稱>:<tag>
```

## 設定自己的網域

先去 DNS 加驗證記錄才能繼續。

### 去中華電信加這筆 TXT 記錄

| 類型 | 名稱 | 值 |
| --- | --- | --- |
| TXT | asuid.api | C2A8DA17FE6D35000DE0EFE154F11B8672A9701F08AA49563F416A7A909F8E4F |

同時也加這筆 CNAME：

| 類型 | 名稱 | 值 |
| --- | --- | --- |
| CNAME | api | my-personal-website-api.greenrock-e5ac13da.westus2.azurecontainerapps.io |

### Step 1：Azure 新增自訂網域

```bash
az containerapp hostname add --name my-personal-website-api --resource-group RuleViewer_group --hostname api.viclai.idv.tw
```

### Step 2：中華電信 DNS 設定

登入中華電信網域管理後台，位置通常在：
會員中心 → 網域管理 → DNS 設定
新增這兩筆：

跑完 Azure 會給你兩筆驗證記錄，類似：

```
TXT  → asuid.api    → 一串驗證碼
CNAME → api         → my-personal-website-api.greenrock-e5ac13da.westus2.azurecontainerapps.io
```

---

### ACR 的 Admin user 被停用了

解決方法：開啟 Admin user

`az acr update --name MyPersonalWebsite --admin-enabled true`

跑完再回到頁面重新整理，錯誤就會消失。

### 去 Azure DNS Zone 加記錄

```bash
# 加 TXT 記錄
az network dns record-set txt add-record --resource-group RuleViewer_group --zone-name viclai.idv.tw --record-set-name asuid.api --value "C2A8DA17FE6D35000DE0EFE154F11B8672A9701F08AA49563F416A7A909F8E4F"

# 加 CNAME 記錄
az network dns record-set cname set-record   --resource-group RuleViewer_group   --zone-name viclai.idv.tw   --record-set-name api   --cname my-personal-website-api.greenrock-e5ac13da.westus2.azurecontainerapps.io

綁定：
az containerapp hostname add --name my-personal-website-api --resource-group RuleViewer_group --hostname api.viclai.idv.tw
az containerapp hostname bind --name my-personal-website-api --resource-group RuleViewer_group --hostname api.viclai.idv.tw --environment managedEnvironment-RuleViewergroup-b75f --validation-method CNAME
```

加完馬上跑驗證：

```bash
nslookup -type=TXT asuid.api.viclai.idv.tw
```

網域綁定成功了，最後一步是開啟免費 SSL 憑證：

```bash
az containerapp hostname bind --name my-personal-website-api --resource-group RuleViewer_group --hostname api.viclai.idv.tw --environment managedEnvironment-RuleViewergroup-b75f --validation-method CNAME
```
